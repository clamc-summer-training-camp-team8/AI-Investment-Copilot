# P1 数据资产治理实施记录（2026-08-30）

> 基线：`phase2-integrated` + 共享集成环境建设成果  
> 范围：历史原件归档、来源授权核验、标题索引治理、受控资产哈希与保留策略  
> 原则：只追加原件修订和处理运行，不覆盖历史切片、事实、事件、embedding 或金标报告

## 1. 基线缺口

迁移前本地真实数据库有 3,792 份业务文档、3,793 条 revision，其中上一阶段盘点记录的
3,790 条历史 revision 没有对象存储原件且授权为待确认。共享环境后新增的正常上传已具备
原件归档，因此实际续跑任务按“文档是否已有活动对象 revision”判断，不用旧 revision 行数
冒充剩余工作量。

历史集合的来源构成为：

| 来源 | 数量 | 治理方式 |
| --- | ---: | --- |
| 巨潮资讯网公告索引 | 3,784 | HTTPS 下载公开 PDF，校验授权域名、PDF 签名和 SHA-256 |
| 遗留本地官方 PDF | 1 | 与公开 URL 原件逐字节 SHA-256 核对后共享不可变对象 |
| 项目自有合成样例 | 5 | 归档带 `is_illustrative=true` 的确定性 JSON 源包 |

来源规则和唯一一条本地映射保存在 `governance/source-policies.json`，不根据正文猜测来源。

## 2. 数据模型与只追加规则

迁移 `0015_data_asset_governance` 增加：

- `document.content_status`：`待核验`、`标题索引`、`原件已归档`、`完整正文`、`合成样例`；
- `source` / `document_revision` 的授权依据、核验人、核验时间；
- revision 去重改为 `(canonical_document_id, content_hash)`，同一不可变对象可被多个业务文档引用；
- `content_hash` 和 `object_key` 保留普通索引，仍支持全局查重和按对象定位。

归档成功只新增：

1. 一个指向 SHA-256 对象键的 `document_revision`；
2. 一个 `source-archive-v1 / archive-only-v1` 成功运行；
3. 必要的来源授权记录。

下载、签名、域名、大小或哈希失败时，在原 legacy revision 下新增 failed run。重试不会删除失败
历史；已有成功对象 revision 的文档会被断点逻辑跳过。

## 3. 标题索引边界

3,784 条行业公告原数据只有标题、披露时间和公开 URL。迁移后：

- `document.content_status=标题索引`；
- 当前正文列清空，标题仍保留在 `document.title`；
- 标题切片标记为 `content_kind=title_index`、`extraction_method=metadata`；
- 候选证据摘录前缀为“公告标题（非正文）”；
- 搜索 API 返回 `content_status`，调用方可以显式展示该边界。

把 PDF 存入对象存储只代表“原件已归档”，不会自动把当前检索内容提升为“完整正文”。后续若要
补正文，必须从该 revision 新建解析运行并产生新的运行级产物。

## 4. CI 哈希与保留策略

`governance/retention-policy.json` 为四类资产定义最低保留期、最低版本数和删除闸门：

| 类别 | 当前保护对象 | 最低保留 |
| --- | --- | ---: |
| Graph Snapshot | 图快照构建/校验契约 | 730 天、至少 2 版本 |
| embedding | `hash-char-2gram-v1` 实现与规格 | 730 天、至少 2 版本 |
| 词表 | `metric-aliases-v1` 独立 JSON | 3,650 天、至少 2 版本 |
| 金标报告 | final gold v3、v6 正式盲测/回执/启用决策 | 3,650 天，不得覆盖 |

`scripts.check_governed_assets` 展开受控文件集，逐文件校验 SHA-256、字节数、类别、版本和保留期。
embedding 额外校验规格中的版本、维度和实现哈希，禁止在版本号不变时静默修改算法。CI、Makefile
和契约测试均已接入该门禁。

Graph Snapshot 继续使用不含节点正文的清单；元数据新增 `include_pending`，并可重新计算
`snapshot_id`。任一层内容哈希或范围字段被篡改时，校验返回失败。

## 5. 操作命令

```powershell
python -m alembic upgrade head
python -m scripts.backfill_source_archives --dry-run
python -m scripts.backfill_source_archives --workers 8 `
  --report .runtime/governance/p1-source-backfill-full.json
python -m scripts.asset_inventory
python -m scripts.check_governed_assets --check
```

任务可安全中断并用同一命令续跑。报告写入 `.runtime/`，其中可能包含失败 URL 相关信息，不纳入
Git；正式验收只提交不含凭证的汇总结果。
