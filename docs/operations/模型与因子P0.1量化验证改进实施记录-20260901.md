# 模型与因子 P0.1 量化验证改进实施记录

- 实施日期：2026-09-01
- 开发分支：`feature/knowledge-answer-intent-routing`
- 方法版本：`portfolio-research-v3`
- 产品边界：受治理的研究验证层，不生成订单、评级、目标仓位或调仓指令

## 1. 实施结论

本轮按量化能力实施路线完成了当前工程和数据条件下可可靠交付的改进：修正行业单例退化和现金期基准错配，增加样本质量分级，将 AI 判断置信度从组合 Alpha 权重中剥离，并建立前后端一致的受治理因子目录。

本轮没有虚构新的人工确认信号、20–30 只证券样本或点时基本面数据，也没有把规划中的动量、波动率因子伪装为已生效能力。当前结果仍属于工程链路和小样本研究验证，不能证明存在稳定 Alpha。

## 2. 方法学改进

### 2.1 信号权重治理

主产品组合分数由：

```text
direction_sign × strength_weight
```

确定。方向和强度必须来自已冻结、可追溯、人工确认的 Evidence Relation。AI 判断置信度继续随信号保存和展示，但 `ai_confidence_used_for_alpha_weight=false`，不会改变组合权重。

旧的单证券兼容接口 `event-backtest-v1` 保留原算法，以保证历史 `QBT-*` 可复算；新的主产品运行通过方法版本和参数策略生成新的 `QPF-*`，不会覆盖 v2 历史记录。

### 2.2 行业单例硬门禁

`portfolio-research-v2` 会对行业内信号去均值；当一个行业只有一只非零信号证券时，该信号会被静默变为零。v3 改为：

- 每个有非零信号的行业至少需要两只证券；
- 不满足时后端返回 422；
- 新建验证页在提交前用冻结信号和点时行业元数据执行同一门禁；
- 行业中性默认关闭，避免稀疏样本在用户不知情时退化。

### 2.3 有效暴露期口径

v3 只在组合前一日存在实际头寸的收益日计算同期基准、跟踪误差、信息比率和 Beta。运行同时保存：

- `active_start_date`、`active_end_date`、`active_trading_days`；
- `benchmark_return`、`excess_return`：有效暴露日匹配口径；
- `full_period_benchmark_return`、`full_period_excess_return`：全区间审计对照。

这样不会再把信号出现前的长期现金期与全区间基准上涨混合成头部超额指标。

### 2.4 样本质量等级

每次运行新增 `validation_quality`：

| 等级 | 自动条件 | 允许结论 |
|---|---|---|
| `engineering_test` | 没有非零信号或没有有效暴露日 | 只证明链路可运行 |
| `insufficient_sample` | 证券少于 20、前瞻观测少于 100，或有效暴露少于 60 日 | 只能描述样本结果 |
| `research_candidate` | 同时达到上述自动门槛 | 可提交独立研究评审 |

所有自动等级的 `alpha_claim_allowed` 均为 `false`；达到研究候选门槛也必须经过独立研究、数据和合规评审。

## 3. 受治理因子目录

新增只读接口 `GET /api/quant/factors` 和前端 `/quant/factors`：

| 因子/约束 | 状态 | 当前用途 |
|---|---|---|
| 人工确认事件方向与强度 | 当前生效 | 唯一 Alpha 输入 |
| ADV20 容量约束 | 当前生效 | 目标资金占用上限 |
| 市场 Beta | 当前生效 | 有效暴露期诊断 |
| 平均净暴露 | 当前生效 | 全区间方向性暴露诊断 |
| 行业中性 | 数据/截面门禁 | 单例行业硬阻断 |
| 点时市值秩中性 | 数据/截面门禁 | 纯 A 股完整截面、至少三只证券 |
| 20/60/120 日动量 | 规划中 | 待扩大事前样本后检验增量解释力 |
| 20/60 日已实现波动率 | 规划中 | 待用于风险分层与波动缩放研究 |
| 点时基本面质量 | 规划中 | 等待合格点时财务数据准入 |

目录返回公式、频率、覆盖范围、输入字段、方法版本、默认启用状态和限制，页面不会把规划项显示为当前回测已经使用的因子。

## 6. 后续数据准入门

以下工作不能仅靠代码在本轮真实完成，继续作为后续阶段门槛：

1. 扩大到至少 20–30 只证券，并事前冻结新的人工确认信号；
2. 累积至少 100 个独立前瞻观测和 60 个有效暴露日，再进入研究候选评审；
3. 准入历史证券池、退市样本、同币种基准、FX、完整涨跌停和结构化公司行动；
4. 在不看结果的前提下冻结动量、波动率和点时基本面因子定义，再做真正 walk-forward；
5. 只有通过独立研究、数据授权和合规评审后，才进入模拟组合与漂移监控；不连接券商执行。
