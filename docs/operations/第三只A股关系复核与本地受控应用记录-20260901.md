## 3. 受控应用机制

新增 `scripts.apply_relation_review_receipt`：

1. 要求调用者提供回执 SHA-256；
2. 逐一复算候选快照、原始/完成工作簿、公告清单和 PDF 哈希；
3. 比对数据库关系的证据、逻辑、假设、状态、方向、强度和候选理由，任一漂移立即拒绝；
4. 验证复核时间带时区、不晚于当前时间且不早于证据披露时间；
5. 只有目标逻辑负责人可以应用；研究员写入 `reviewed_by`，实际操作人写入审计日志；
6. 相同结果重复执行保持幂等，不生成重复审计。

单元测试覆盖正常应用、幂等、候选漂移、倒签/未来时间、非负责人和附件哈希漂移。
