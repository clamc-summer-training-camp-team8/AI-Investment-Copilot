## 3. 运行不可变绑定

新运行参数包含：

```json
{
  "model_template_id": "confirmed-event-research-v3",
  "model_template_version": "3.0.0",
  "factor_versions": {
    "confirmed_event_direction_strength": "1.0.0",
    "adv20_capacity": "1.0.0",
    "industry_neutralization": "1.0.0",
    "point_in_time_market_cap_rank": "1.0.0"
  }
}
```

上述字段进入确定性运行哈希，因此模板或因子版本变化会形成新的 `QPF-*` 编号。已有历史记录
不做数据库回填，结果页明确显示“历史运行未绑定模板”。

## 4. 产品融合

- 工作台当前实际使用的“研究功能”导航新增 `/quant`，并受 `quant_research_enabled` 控制；
- 投资逻辑详情新增“进入模型验证”，传递 `thesisId` 和 `securityId`；
- 新建验证只把研究上下文用于返回路径和证券预选，真实 Alpha 输入仍来自所选冻结信号集；
- 模板页可进入因子定义和带模板参数的新建验证；
- 运行详情同时展示模型、行情、信号和方法四类来源。

浏览器验收时发现 AI 助手浮动按钮与粘性运行按钮重叠，已为桌面提交栏增加右侧安全间距，
移动端恢复常规内边距。修正后真实点击成功进入运行详情。
