## 1. 实施结论

本轮已完成“模型与因子”P0 主链开发。产品现在支持从受治理冻结行情和人工确认信号出发，完成研究概览、信号来源追溯、新建组合验证、运行结果分析和历史运行复看。

## 2. 已交付功能

### 2.1 产品导航与页面结构

- 将前端产品名称统一为“模型与因子”，保留 `/quant` 作为规范入口。
- 新增独立懒加载量化模块及二级导航：
  - `/quant`：研究概览；
  - `/quant/signals`：研究信号集；
  - `/quant/signals/:signalSetId`：信号来源详情；
  - `/quant/new`：新建组合验证；
  - `/quant/runs`：本人历史运行；
  - `/quant/runs/:runId`：不可变运行详情。
- 数据中心行情详情可携带 `marketDatasetId` 跳转到 `/quant/new`，避免丢失用户已选版本。
- 模块受 `quant_research_enabled` 功能开关控制，关闭时不展示导航且 API 返回 404。

### 2.2 研究概览与冻结输入

- 展示后端显式默认数据集，不按版本时间猜测默认值。
- 同时展示已登记候选/历史版本及冻结状态、覆盖区间、复权口径、证券数和 Manifest 哈希。
- 对 V3 展示经真实资产验证的事实：9 只证券、5,937 条行情、4,649/4,649 条 A 股证券日具备点时市值。
- 展示人工确认信号集、内容哈希、冻结时间和 Alpha 评测轨。
- 显式展示语义、检索、Alpha 三轨隔离边界。

### 2.3 信号来源与权限

- 新增 `GET /api/quant/signal-sets/{signal_set_id}`。
- 信号详情返回披露时间、生成时间、方向、强度、置信度、人工确认状态、Evidence、Relation、Thesis、Hypothesis、来源定位和文档信息。
- 服务端逐条复用逻辑可见性和文档授权判断；无权用户不能借冻结信号集绕过原始证据权限。
- 前端提供“查看证据”“查看逻辑”“源资料”跳转，只呈现后端确认可见的来源。

### 2.4 新建组合验证

- 只允许选择行情数据集与当前可见信号集共同覆盖的证券。
- 支持配置区间、初始资金、滚动窗口、测试窗口、再平衡周期、成本、滑点、个股/行业上限、容量约束、行业中性、市值中性和研究型空头。
- 运行前执行以下门禁或警告：
  - 日期不得超出冻结数据覆盖范围；
  - 信号生成时间不得晚于行情截止日；
  - 市值中性至少需要三只证券；
  - 所选区间存在点时市值缺口时阻断市值中性；
  - CNY/HKD 混合但 FX 未冻结时保留解释限制；
  - 涨跌停状态和结构化公司行动能力不足时保留研究限制。
- 成功运行后跳转到稳定的 `/quant/runs/:runId`，运行绑定行情、信号、方法与参数版本。

### 2.5 结果分析与历史复看

- 展示组合收益、基准收益、超额收益、最大回撤、跟踪误差、信息比率和 Beta。
- 使用内置 SVG 绘制组合/基准净值曲线，不增加图表依赖。
- 展示 Walk-forward 样本外窗口、IC、Rank IC、分位收益、证券风险贡献、行业风险贡献和因子暴露。
- 展示输入/接收/跳过信号、阻断交易、诊断警告、方法版本、Manifest/信号哈希和完整运行参数。
- 历史页支持按名称、QPF 编号、数据集、信号集和方法版本检索。

### 2.6 治理与受控操作

- 普通产品 API 不再允许任意登记默认行情。
- `POST /api/quant/market-datasets/register-default` 需要同时满足：
  - `quant_dataset_api_registration_enabled=true`；
  - 管理员身份，或属于 `quant_governance_teams` 配置的治理团队。
- 正式候选发布仍使用受控命令；登记与默认版本切换保持分离。

## 5. 已知限制与后续边界

- V3 继续是候选版本，不因本次开发自动成为默认版本。
- V3 截止 2026-08-28，不能承接 2026-08-31 后确认的第三条信号；前端会阻断信号晚于行情截止日的运行。
- 港股缺少点时市值，A/H 混合组合不得启用市值中性。
- CNY/HKD 汇率尚未冻结，混合币种结果只能用于内部研究解释。
- 涨跌停参考仍有 3 个证券日缺口，结构化公司行动事件未准入；界面保留明确警告。
- 当前前端生产包存在仓库既有的大分块警告，不影响构建通过；后续可按路由继续拆分公共 `pages.tsx`。

## 6. 回滚方式

- 设置 `QUANT_RESEARCH_ENABLED=false` 可同时关闭导航与量化 API。
- 未修改 `QUANT_DEFAULT_MARKET_MANIFEST`，现有默认数据版本无需回滚。
- 新页面为独立懒加载模块；必要时可回退 `/quant/*` 路由而不影响工作台、投资逻辑、数据中心和复盘中心。
