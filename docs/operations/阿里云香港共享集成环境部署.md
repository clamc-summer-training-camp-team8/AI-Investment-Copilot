# 阿里云香港共享集成环境部署

> 目标：在阿里云中国香港 ECS 上运行低流量共享集成与动态演示环境。  
> 形态：单机 Docker Compose；后续达到迁移阈值再拆分托管服务。  
> 集成候选分支：`phase2-integrated`；正式发布基线：通过门禁后合入 `main` 的版本标签。

本次建设过程、问题修复和完整验收证据见
[共享集成环境建设工作日志（2026-08-30）](./共享集成环境建设工作日志-20260830.md)。

## 1. 当前实例结论

中国香港的 Ubuntu 22.04 ECS 可以直接运行现有完整栈，不需要为备案等待期额外引入 ACK、ACS
或 SAE。2 vCPU、4 GiB 内存、40 GiB 云盘用于低流量交付时采用单 API 进程、单 ARQ Worker
进程和串行文档处理；主机初始化脚本创建 4 GiB swap 作为突发保护。

该环境包括 Caddy、React/Nginx、FastAPI、Worker、PostgreSQL/pgvector、Redis 和 MinIO。
Graph RAG 默认开启，动态页面连接实际 API、共享数据库、对象存储和任务队列。

## 2. 必要前置条件

1. ECS SSH 使用密钥认证，并把发布工作站的公钥加入实例。
2. 安全组公网入方向只开放 80、443；22 只允许团队办公出口 IP。
3. 5432、6379、8000、8080、9000、9001 不得在安全组中开放。
4. 推荐准备一个解析到 ECS 公网 IP 的域名。没有域名时可以暂时把公网 IP 作为
   `SiteAddress`；脚本会设置 `INTEGRATION_TLS_ARGUMENT=internal` 并使用内部 CA，浏览器不会默认
   信任。正式团队演示应使用域名，此时脚本会配置公开 ACME 证书。
5. 本机 Docker Desktop、OpenSSH 客户端和项目测试环境正常。

公网 IP 转为 EIP 可以避免未来更换实例时入口改变，但不是首次发布的阻塞项。

## 3. 一键首次发布

从仓库根目录运行：

```powershell
.\deploy\alibaba-cloud\publish-local.ps1 `
  -ServerAddress "<ECS公网IP>" `
  -SshUser "root" `
  -IdentityFile "$env:USERPROFILE\.ssh\<实例私钥>" `
  -SiteAddress "integration.example.com" `
  -AcmeEmail "platform-owner@example.com" `
  -InitialUser "integration_admin"
```

脚本按顺序执行：

1. 验证 SSH 密钥连接；
2. 安装并配置 Docker Engine、Compose v2、日志轮转与 swap；
3. 优先通过 Docker SSH transport 把受 `.dockerignore` 过滤的当前工作树发送到 ECS 构建应用和
   Web 镜像，避免跨境上传数百 MB 镜像归档；若远程 Docker transport 不可用，则回退到本地
   构建、gzip 压缩和 SCP 传输；
4. 以唯一发布号标记两份不可变镜像，并把 Compose、网关和运维脚本通过 SCP 传输；
5. 首次发布生成数据库、Redis、MinIO 与 JWT 签名密钥；
6. 运行迁移、初始化对象桶并启动完整栈；
7. 等待 `/health/ready` 确认数据库、队列、Worker 和对象存储全部就绪；
8. 失败时恢复上一版 `release.env`。

首次成功时控制台只显示一次初始账号密码，账号进入数据库并要求首次登录改密。真实运行密钥只
保存在 ECS 的 `/opt/ai-investment-copilot/deploy/.env.integration`，权限为 0600。重复发布会保留
既有密钥和产品账号，避免持久卷仍使用旧密码而导致服务不可用。

## 4. 域名与 HTTPS

把域名 A 记录解析到 ECS 公网 IP，确认 80/443 已开放后再执行发布。Caddy 会自动申请和续签
公开受信任证书。访问入口为：

```text
https://<SiteAddress>/operations
```

只使用公网 IP 时，入口仍是 `https://<公网IP>/operations`，但需要团队设备显式信任 Caddy
内部根证书；不要退回明文 HTTP 传输登录密码或 JWT。

域名必须先存在并把 A 记录解析到 ECS 公网 IP。解析生效后，在仓库根目录执行：

```powershell
.\deploy\alibaba-cloud\set-domain.ps1 `
  -ServerAddress "47.238.244.65" `
  -IdentityFile "$env:USERPROFILE\.ssh\id_rsa" `
  -Domain "inverstcopilot.com" `
  -AcmeEmail "platform-owner@example.com"
```

脚本会在本地和服务器双重校验 A 记录，备份 `.env.integration`，原子更新站点地址、TLS 与 CORS，
等待 Caddy 公开证书和 API 就绪；失败会自动恢复原 IP 配置。

## 5. 发布后验收

服务器侧：

```bash
cd /opt/ai-investment-copilot/deploy
docker compose -f docker-compose.integration.yml \
  --env-file .env.integration --env-file release.env ps
docker compose -f docker-compose.integration.yml \
  --env-file .env.integration --env-file release.env \
  exec -T api python -c \
  "import urllib.request; print(urllib.request.urlopen('http://127.0.0.1:8000/health/ready').read().decode())"
```

浏览器验收：

1. `/operations` 展示产品登录页，受保护 API 在未认证时返回 401；
2. 每位成员以独立账号登录，首次进入前完成密码修改；
3. 登录后打开 `/operations`，页面数据来自 API 而不是静态样例；
4. 上传一份授权材料，确认任务进入 Redis 并由 Worker 完成；
5. 执行文本检索和 Graph RAG 检索，检查证据与图关系结果；
6. 更新一家公司唯一投资逻辑，第二个账号刷新后可看到变更；
7. 检查操作人身份和审计记录可区分。

## 6. 备份与运维

每日低峰执行：

```bash
sudo bash /opt/ai-investment-copilot/deploy/integration/backup.sh
```

备份必须复制到 ECS 之外。首期可由受控运维机通过 SCP 拉取；后续接入阿里云 OSS。至少保留
数据库 dump、对象版本归档、对象内容哈希、镜像清单和 `SHA256SUMS`。每月运行一次隔离恢复：

```bash
sudo bash /opt/ai-investment-copilot/deploy/integration/restore-drill.sh \
  /opt/ai-investment-copilot/backups/<UTC时间戳>
```

最低告警包括磁盘 70%、内存 80%、容器重启、`/health/ready`、Redis 队列积压和最近一次备份。
达到 5 名以上日活成员、50 GiB 数据或对外试点时，评审迁移至 RDS PostgreSQL、Tair 和 OSS。
