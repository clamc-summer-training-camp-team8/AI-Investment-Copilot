## 1. 交付结论

P2 的工程闭环已经完成。原量化页把 80 个交易日和 4 条信号放在浏览器内，本轮改为：

```text
授权策略
  → 冻结行情 / 交易日历 / 公司行动登记簿（清单 + SHA-256）
  → 人工确认信号集（内容哈希）
  → 确定性组合回测（参数哈希）
  → PostgreSQL 历史运行 / 页面复看
```

语义金标、检索排序报告和 Alpha 验证分别使用
`gold_semantic_accuracy`、`retrieval_ranking_quality`、`alpha_validation` 三条轨道。量化表的
数据库约束只接受 `alpha_validation`；任何候选信号都必须绑定已确认的证据与关系编号，并保留
真实披露、人工确认和信号生成时间。信号生成不得早于关系人工确认，不能把事后确认回填成历史时点。

## 3. 组合研究能力

`portfolio-research-v2` 提供：

- T+1 可交易日执行、未来数据泄漏隔离、停牌与涨跌停方向性交易阻断；
- 多证券权重、个股/行业上限、行业去均值和点时市值秩残差中性化；
- ADV20 × 参与率容量上限、成本、滑点、组合换手和现金暴露；
- 滚动观察窗口、walk-forward 分段报告、IC、Rank IC 和五分层收益；当前不含窗口内模型重训练或选参；
- 组合收益、基准、跟踪误差、信息比率、Beta、最大回撤；
- 基于协方差的证券、行业风险贡献，以及市场、市值和净暴露因子审计。

所有收益与风险数值均在 `app/calc` 中使用确定性程序计算，AI 不参与。

## 5. 数据就绪门禁

下列缺口被明确建模为能力状态，不用估算值填补：

1. 点时市值未覆盖。`daily_basic` 单日查询实测可用，但当前全区间查询返回为空；市值中性算法由合成点时数据单测，默认真实行情的页面开关禁用，后端强制
   返回 422；禁止用当前市值回填历史造成未来数据泄漏。
2. 结构化公司行动事件流未覆盖。登记簿已独立冻结但事件数为 0；前复权效果可使用，不能宣称
   完成逐事件复权审计。
3. 涨跌停独立状态未覆盖。Tushare `daily` 可用、`stk_limit` 实测无权限；引擎不假造状态。
4. `trade_cal` 单日有权限但实测每小时仅一次；主构建不消耗该配额，完整日历双源门禁暂不启用。
5. 港股/HKD 与人民币行业基准存在币种错配；冻结 FX 前不得解释为可交易 Alpha。

因此 P2 是“产品工程已完成、数据能力按清单逐项准入”，不是“所有供应商数据已经采购完成”。
