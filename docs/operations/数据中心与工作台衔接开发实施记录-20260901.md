# 数据中心与工作台衔接开发实施记录

> 日期：2026-09-01  
> 开发分支：`feature/knowledge-answer-intent-routing`  
> 开发基线：`370a89e` 及 `docs/collaboration/20260901-phase3三分支功能集成合并记录.md`

## 1. 开发目标

把三分支合并后并存的工作台和数据中心收敛为一条连续的产品路径：工作台负责呈现今日研究变化、待确认影响和研究上下文，数据中心负责承接这些变化使用的研究资料、原件、Revision、来源授权和处理运行。两边共享顶部产品导航、视觉密度和稳定深链，不复制第二套资料读取能力。

## 2. 本次完成内容

### 2.1 产品外壳与视觉对齐

- 数据中心改为与工作台一致的“固定顶部导航 + 全宽内容区”外壳；
- 移除数据中心页面中的旧侧栏、旧工作区上下文条、移动底栏和重复免责声明；
- 新增数据中心产品头部、返回工作台和上传资料操作；
- 卡片、指标、标签页、详情头部、圆角、边框、阴影和响应式密度统一到工作台视觉体系；
- 窄屏时保留当前激活的“数据中心”顶部入口，避免只显示“工作台”造成位置丢失。

### 2.2 工作台到数据中心

- 工作台右栏新增真实 API 驱动的数据资产摘要：可见资料、完整正文和近七日失败运行；
- “查看采集状态”调整为“查看数据运行”，直达 `/assets/runs?from=workbench`；
- 覆盖区的数据中心入口携带工作台来源；
- 公司变化资料数量可按 `security_id` 和入库时间进入研究资料目录；
- 单条变化读取 API 已有的 `source_document_id`，可直达受治理资料详情；缺少该标识时安全降级到公司资料目录。

### 2.3 数据中心返回工作台

- 数据中心识别 `from=workbench`，显示来源提示和返回今日研究视图入口；
- UI 来源参数不会透传到资料或运行 API；
- 资料目录进入详情时继续保留工作台来源；
- 详情页返回入口区分普通目录和工作台资料视图；
- 清空目录筛选时保留工作台来源，不中断返回链。

### 2.4 加载性能

- 数据中心由静态导入改为路由级动态加载；
- 生产构建生成独立数据中心 JavaScript 分包约 `31.24 kB`（gzip `8.71 kB`）；
- 主包仍约 `612.35 kB`，继续存在 Vite 的 500 kB 非阻断警告，后续需再拆分 `pages.tsx` 中的公司、更新和量化页面。
