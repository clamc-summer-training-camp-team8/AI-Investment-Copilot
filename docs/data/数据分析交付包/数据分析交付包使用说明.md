# AI Investment Copilot 数据分析交付包 V1.0

## 使用顺序

1. 阅读《数据分析需求与Alpha验证说明书》，确认职责边界、数据对象和验收口径。
2. 使用《投研数据资产与指标字典》完成真实数据源盘点和指标口径确认。
3. 使用《投资逻辑与Alpha候选信号验证台账》贯通逻辑、事件、信号、结果与实验。
4. 使用“业务样例包”进行首次联调，再将虚拟案例替换为已授权的真实案例。
5. 由研究员或业务导师确认投资逻辑、经济含义、同业范围、基准和人工标准答案。

## 文件职责

- 主说明书：定义数据分析师要解决的问题、输入输出和验收边界。
- 数据资产与指标字典：维护数据源、字段、指标、质量、权限与血缘。
- 信号验证台账：维护投资逻辑全链路和Alpha候选信号实验。
- 样例案例包：提供虚拟资料、人工标注、指标数据和预期结构化输出。

## 重要边界

- 样例数据全部为虚构，不构成投资建议。
- MVP重点验证效率价值、研究质量和候选信号的增量信息价值。
- 复杂因子挖掘、组合回测和归因分析在P2通过专业量化平台完成。
- 所有正式结论必须记录数据版本、模型版本、样本范围、基线和人工复核。
