# 数据中心功能模块需求文档

> 文档版本：v1.0
>
> 日期：2026-08-31
>
> 状态：待评审
>
> 适用基线：`phase3-database-auth-reconciliation` / `99e8390`，以及已完成的 Phase 2 集成、共享集成环境、P1 数据资产治理和 P2/P2.1 量化数据工程成果
>
> 目标路由：`/assets` 及其子路由
>
> 产品边界：数据发现、状态查看、谱系追溯和受控治理；不承担研究结论生成、模型质量放量或交易执行

## 1. 需求摘要

当前顶部导航已经把 `/assets` 命名为“数据中心”，但页面内容仍是面向开发与治理验收的“资产治理”
单页：只能查看聚合数量、重建检索索引并验证混合召回。底层已经具备 3,792 份活动文档、不可变
revision、追加式处理运行、对象存储归档、来源授权、版本化 embedding、冻结量化行情、信号集和
增量生产链路，但研究员和数据管理员无法在产品内完成以下基本任务：

- 按公司、行业、来源、时间和内容状态查找资料；
- 打开单份资料，查看原件、授权、修订、解析产物和处理历史；
- 明确区分“原件已归档”“标题索引”和“完整正文”；
- 查看当前量化数据版本、覆盖范围、能力边界、清单哈希和默认版本；
- 发现失败、待解析、待授权、数据延迟或候选待发布等需要处理的状态；
- 从全局搜索、知识库问答、任务中心或量化实验稳定跳转到同一份数据资产。

本次开发把现有“资产治理”页升级为产品级“数据中心”，形成统一的数据目录和追溯入口。第一版
优先解决“看得见、找得到、说得清、追得回”，写操作继续受权限和人工闸门控制。

## 2. 建设依据与当前基线

### 2.1 已有能力

| 能力 | 已有状态 | 数据中心可复用内容 |
| --- | --- | --- |
| Phase 2 集成 | Graph RAG、Agent、排序先验、前端产品页已统一 | 保持现有路由、Graph 追踪和人工确认边界 |
| 共享集成环境 | Web、API、Worker、PostgreSQL/pgvector、Redis、MinIO 真实运行 | 数据中心必须使用真实 API 和共享数据状态 |
| 产品内身份 | JWT 登录、独立团队账号、首次改密和审计身份已落地 | 所有列表、详情和操作按 Actor 鉴权 |
| 文档治理 | 3,792 份活动文档均有对象归档和已核验授权 | 可形成文档目录、来源和归档状态视图 |
| 内容治理 | 3,784 份为“标题索引”，不冒充完整正文 | 页面必须持续展示这一边界 |
| 数据谱系 | 7,582 条 revision、11,373 条处理/归档运行及运行级产物 | 可形成单文档 revision/运行时间线 |
| 文档检索 | `GET /api/assets/hybrid-search` 已支持权限优先混合召回 | 可复用为资料搜索，但仍需列表型查询 |
| 文档操作 | 已有重处理、可见性修改、软删除和索引重建服务 | 需要按后端返回权限暴露受控操作 |
| 量化数据 | 不可变行情数据集、信号集、回测运行和 `/api/quant/catalog` 已落地 | 可形成量化数据目录和版本详情 |
| 增量生产 | 工作日探测、候选隔离、低频参考缓存和 CI 告警已落地 | 后续可展示新鲜度、最近运行和候选状态 |
| 全局搜索/问答 | 已有需求与开发计划，当前工作区正在开发相关能力 | 数据中心需接受搜索跳转参数并复用原文抽屉 |

### 2.2 当前页面缺口

现有 `AssetPage` 只有三块内容：资产聚合指标、历史质量盘点、权限感知混合召回。当前 API 也主要
提供聚合盘点和检索命中，尚未提供产品所需的分页文档目录、文档详情、来源目录、运行目录及量化
刷新运行接口。

因此本需求是“前端数据中心模块 + 必要的只读查询契约”，不是单纯修改样式。前端不得直接读取
数据库、MinIO 对象键、服务器 `.runtime` 报告或仓库冻结文件来补齐接口缺口。

## 3. 产品目标与成功标准

### 3.1 产品目标

1. 研究员可在 3 次以内操作找到目标资料并打开可核验的原文或状态详情。
2. 数据管理员可从总览发现待授权、缺归档、待解析、失败运行和行情延迟，并定位到具体对象。
3. 每份文档都能追溯到来源、授权依据、不可变 revision、处理运行、解析产物和可见性。
4. 每个量化数据集都能说明来源、覆盖期、证券范围、能力矩阵、限制、清单哈希及默认状态。
5. 数据中心与全局搜索、知识库问答、任务中心、质量中心和量化实验共用稳定资产标识和深链。
6. 页面展示严格继承后端口径，不在浏览器重新计算质量、覆盖率、哈希、收益或能力准入状态。

### 3.2 首版成功指标

| 指标 | 目标 |
| --- | ---: |
| 文档列表/筛选请求 P95 | ≤ 2 秒 |
| 文档详情请求 P95 | ≤ 3 秒 |
| 已返回原文 locator 可打开率 | 100% |
| 标题索引误展示为完整正文 | 0 |
| 越权对象标题、数量、详情或原文泄漏 | 0 |
| 量化数据清单哈希与数据库登记不一致仍显示“可用” | 0 |
| 列表筛选、分页、刷新后 URL 状态恢复成功率 | 100% |
| 关键治理操作审计覆盖率 | 100% |

### 3.3 非目标

第一版不包含：

- 对 3,784 份标题索引公告自动执行全量 OCR/正文解析；
- 在前端上传并替换量化行情文件、编辑 manifest 或修改 SHA-256；
- 互联网实时检索、外部数据市场采购或供应商账户管理；
- 将质量中心的金标、RAG 评测和模型放量决策迁入数据中心；
- 将量化实验的组合回测、风险归因和收益结果迁入数据中心；
- 在浏览器中执行指标计算、回测、embedding、Graph 构建或数据转换；
- 物理删除对象版本、历史 revision、正式金标或已冻结量化版本；
- 券商连接、订单、评级、调仓指令或自动发布候选数据集；
- 第一版内建设复杂 BI 驾驶舱或装饰性图表。

## 4. 目标用户与权限边界

### 4.1 目标用户

| 用户 | 核心诉求 | 首版权限 |
| --- | --- | --- |
| 研究员 | 找资料、看原文、确认来源与内容状态、进入研究上下文 | 查看有权访问的目录/详情/原文，不执行治理写操作 |
| 量化研究员 | 选择可复算的数据版本、确认覆盖与能力限制 | 查看已登记冻结行情和信号集，跳转量化实验 |
| 数据/资产管理员 | 查看全局治理缺口、重处理、调整可见性、重建索引 | 在后端授权范围内执行治理操作 |
| 研究负责人/复核人 | 回查证据来源、处理历史和数据限制 | 查看团队范围资产，跳转任务/质量中心复核 |
| 只读成员 | 浏览被授权资产和已公开状态 | 无上传、重处理、可见性修改和删除能力 |

### 4.2 权限原则

- 前端不根据团队名称自行推断权限；API 返回 `allowed_actions` 或省略不可执行操作。
- 列表、聚合、筛选选项和详情均在后端按 Actor 过滤，不返回“不可见对象数量”。
- 无权限与不存在统一按 404 处理，避免通过 ID 枚举资产。
- 原件预览、下载和片段打开必须再次鉴权；不得把永久 MinIO 地址或对象密钥直接发给浏览器。
- 写操作必须记录操作者、对象、操作、前后状态、原因和时间；审计中不记录正文或凭证明文。
- 当前 `analyst-mvp` 的兼容授权应在正式角色模型落地后迁移，不能继续作为长期管理员口径。

## 5. 信息架构与页面职责

### 5.1 一级结构

`/assets` 保持顶部导航“数据中心”，页面内使用四个二级入口：

| 二级入口 | 建议路由 | 核心内容 |
| --- | --- | --- |
| 数据总览 | `/assets` 或 `/assets/overview` | 文档与量化资产摘要、需要关注项、最近运行 |
| 研究资料 | `/assets/documents` | 文档列表、筛选、搜索、详情、原件与谱系 |
| 量化数据 | `/assets/market-datasets` | 冻结行情版本、信号集、覆盖、能力和限制 |
| 数据源与运行 | `/assets/runs` | 来源授权、解析/归档运行、行情刷新状态和失败定位 |

文档详情使用 `/assets/documents/{documentId}`。量化数据详情使用
`/assets/market-datasets/{datasetId}`。若采用详情抽屉，也必须同步更新 URL，保证刷新、复制和从其他
页面进入时能恢复同一对象。

### 5.2 与其他模块的分工

| 模块 | 负责 | 不负责 |
| --- | --- | --- |
| 数据中心 | 数据目录、内容状态、来源、版本、谱系、运行与受控治理 | AI 结论、金标发布、回测计算 |
| 全局搜索 | 跨公司/逻辑/事件/资料的快速发现与跳转 | 展示完整资产谱系 |
| 知识库 AI 问答 | 基于可见正文生成带引用候选回答 | 修改数据资产或确认关系 |
| 任务中心/复核 | 处理待办、失败重放、人工裁决 | 作为全量数据目录 |
| 质量中心 | 金标、检索评测、Graph RAG 放量门禁 | 文档与行情日常治理 |
| 量化实验 | 选择冻结数据并运行确定性研究回测 | 管理来源授权和数据版本生命周期 |

## 6. 功能需求

### 6.1 数据总览

#### FR-DC-001 总览指标

首屏显示后端聚合的业务指标，不把数据库技术表数量作为唯一主信息：

- 活动研究资料数；
- 已归档原件数及缺失数；
- 完整正文、标题索引、待核验等内容状态分布；
- 授权已核验及待确认数；
- 近 24 小时/7 日成功与失败处理运行；
- 已登记冻结行情版本数、当前默认版本、最新覆盖日期；
- 数据能力异常数，例如行情过期、缺市值、缺 FX、候选待发布。

点击指标进入相应列表并自动带入筛选。指标必须显示统计口径和 `as_of`，不能用前端已有列表长度
冒充全量数量。

#### FR-DC-002 需要关注

按优先级展示可行动的问题：缺对象归档、授权待确认、解析失败/死信、标题索引待解析、默认行情
过期、候选构建失败、候选待人工发布、来源权限变化。每项显示数量、最近发生时间、影响范围和目标
入口。

低权限用户只看到自己可处理或可见的事项。若当前没有问题，展示真实空态，不构造演示告警。

#### FR-DC-003 最近运行

展示最近的文档归档/解析、检索索引、量化行情刷新和低频参考缓存运行，至少包含：运行类型、状态、
开始/结束时间、处理数量、失败数量、触发方式和追踪 ID。点击进入运行详情或任务中心。

### 6.2 研究资料目录

#### FR-DC-010 分页列表

资料列表必须由服务端分页，默认每页 20 条、最大 100 条。默认按披露时间倒序，披露时间缺失时按
入库时间倒序。每行至少显示：

- 标题、资料类型、来源；
- 关联证券/公司与行业；
- 披露时间和入库时间；
- 内容状态；
- 原件归档与授权状态；
- 最新处理运行状态；
- 可见性；
- 更新时间及可执行操作。

长标题和多证券关系需要可访问的截断/展开方式；状态不能只用颜色表达。

#### FR-DC-011 搜索与筛选

支持以下筛选，全部写入 URL 查询参数：

- `q`：标题、资料编号和可检索正文；
- 公司/证券、行业；
- 来源、资料类型；
- 内容状态：标题索引、完整正文、原件已归档、待核验、合成样例；
- 授权状态、归档状态、最新运行状态；
- 可见性；
- 披露日期范围；
- 排序字段和方向。

顶部全局搜索的“查看全部资料”使用
`/assets/documents?q=<query>`。数据中心接受该参数后立即执行搜索并保留来源入口信息。

输入搜索使用防抖和过期响应保护；改变筛选时回到第 1 页；清空筛选后恢复默认排序。筛选选项本身
也必须按当前 Actor 可见范围生成。

#### FR-DC-012 列表状态

- 首次加载显示结构化骨架；后台刷新不清空已有列表。
- 空结果区分“当前没有资料”和“筛选条件下没有匹配资料”。
- API 失败保留筛选和搜索输入，允许重试。
- 分页越界时回到最后一个有效页，不显示空白页面。
- 未登录或令牌过期沿用统一登录恢复流程，不在页面内伪装成空数据。

#### FR-DC-013 批量操作

第一版仅为资产管理员提供风险可控的批量操作：提交重处理、调整可见性。批量重处理必须先展示
目标数量、内容状态和预计动作；单次上限由后端控制。批量软删除、原件下载和数据导出不纳入首版。

### 6.3 文档详情与谱系

#### FR-DC-020 资料摘要

详情页顶部显示标题、文档 ID、类型、来源、披露时间、关联证券/行业、可见性、授权和内容状态。
标题索引必须固定显示高可见提示：

> 当前仅有公告标题可检索；原件已归档不等于正文已解析，不能据此核验正文事实。

“完整正文”也必须指明对应的活动 revision 和成功处理运行，不能仅凭对象存在判断。

#### FR-DC-021 原件与片段

- 有权用户可以预览或下载当前活动原件；每次请求生成短时授权响应并记录审计。
- 已解析资料显示可分页/按 locator 打开的片段，支持前后片段导航和高亮目标 locator。
- 从全局搜索、AI 引用或证据页进入时，详情页打开指定 locator。
- 原件无法浏览时允许下载，但不得跳转未经校验的外部 URL 作为唯一回查路径。
- 标题索引只显示标题元数据和“提交解析/查看原件”，不显示伪正文阅读器。

#### FR-DC-022 来源与授权

展示来源名称、来源类型、授权状态、授权依据摘要、核验人/时间、公开来源域名和使用限制。Token、
内部密钥、本地文件路径和授权证明原文不得返回前端。

#### FR-DC-023 Revision 与处理运行

以时间线展示不可变 revision，包含 revision ID、内容 SHA-256 短值、对象版本、创建时间、来源 URL
域名、授权状态、是否活动和 tombstone 状态。选中 revision 后展示其处理运行：解析器、切片器、
抽取器、embedding 版本、状态、产物数量、质量摘要、错误类型和时间。

前端只显示后端已经核验的哈希和质量结论，不重新下载文件计算。失败运行与后续成功重试均需保留，
不得只展示最新成功记录抹去历史。

#### FR-DC-024 受控操作

后端按对象返回允许操作：

- 重新处理当前活动 revision；
- 修改可见性；
- 重建检索索引（全局管理员动作，放在运行页而非每行）；
- 软删除/恢复活动文档；
- 跳转任务中心处理失败或人工复核。

每个写操作显示影响说明和结果状态。软删除必须二次确认文档标题/编号，说明对象与历史 revision
不会被物理删除。发生 409/422/503 时保留页面上下文并显示可执行的恢复建议。

### 6.4 量化数据目录

#### FR-DC-030 行情数据集列表

列表展示已经登记的不可变行情数据集，包含：数据版本、数据集 ID、默认标记、冻结状态、来源组合、
复权口径、覆盖起止、最新交易日、证券数、冻结人/时间、manifest SHA-256 短值和能力状态。

默认版本由后端配置与登记记录共同确认。未登记候选不能显示为“默认”或“可用于研究”。

#### FR-DC-031 行情数据集详情

详情至少展示：

- 数据集基本信息、manifest 与各子资产哈希校验状态；
- 证券、行业基准、市场和币种覆盖；
- 行情、日历、公司行动、来源快照和跨源质检规模；
- 来源优先级和降级原因；
- 能力矩阵：点时市值、容量约束、涨跌停阻断、公司行动、FX 等；
- 已知限制和不允许的研究解释；
- 关联信号集和历史运行数量；
- 跳转“使用此版本进入量化实验”。

能力按实际证券范围展示。例如 A 股点时市值可用不能被前端概括为混合 A/H 组合均可市值中性；
未冻结 FX 时仍需明确阻断混币种 Alpha 解释。

#### FR-DC-032 信号集

量化数据页可查看已冻结信号集的名称、版本、轨道、信号数量、内容哈希、冻结人/时间和关联证据。
只有 `alpha_validation` 且满足人工确认和点时要求的信号集才能标记为“可用于组合研究”。候选证据、
语义金标和检索标签不得显示为可用信号集。

#### FR-DC-033 候选与发布状态

量化增量任务生成候选时，数据中心展示候选 ID、覆盖截止日、运行状态、门禁摘要、报告时间和
“待人工发布”状态。第一版只允许有权管理员打开发布检查清单并跳转到受控发布流程；不得在列表中
一键自动切换默认版本。

在刷新运行尚未持久化为产品记录前，本功能可作为后续增强项；禁止前端直接读取 CI artifact 或
服务器本地报告伪装成正式 API。

### 6.5 数据源与运行

#### FR-DC-040 数据源目录

显示公开披露、用户上传、项目自有、AKShare 聚合上游和 Tushare 兼容补充接口等来源。每项包含
来源类型、授权状态、使用范围、最后核验时间、关联资产数和最近运行状态。

对于兼容 API Origin，只显示经过脱敏的来源标识和登记类型，不把它描述为官方 Tushare 服务，也不
展示 Token、完整内部地址或凭证来源。

#### FR-DC-041 运行目录

统一查看文档归档/解析、检索索引、行情刷新和低频参考缓存运行。支持按运行类型、状态、时间和
触发方式筛选。状态至少包括 queued/running/succeeded/failed/dead_letter/noop/candidate_built。

不同运行类型可以使用统一外壳，但详情字段按契约分型，禁止前端依赖随意 JSON 拼接业务文案。

#### FR-DC-042 运行详情与恢复

详情展示运行 ID、目标资产、代码/数据版本、触发人或调度器、开始/结束时间、耗时、处理计数、
脱敏错误分类、重试次数、产物/候选标识和审计链。可恢复动作仍复用任务中心的重放或发布流程。

数据中心负责“发现和追溯”，任务中心负责“执行待办”。同一运行状态不得在两个页面产生互相冲突
的写操作。

### 6.6 跨模块深链与通用交互

#### FR-DC-050 深链

至少支持：

- `/assets/documents?q=毛利率&content_status=完整正文`
- `/assets/documents/{documentId}?locator={encodedLocator}`
- `/assets/market-datasets/{datasetId}`
- `/assets/runs?status=failed&type=ingestion`

参数无效时忽略单个无效筛选并给出提示；对象无权访问时按统一 404，不回退到包含敏感标题的页面。

#### FR-DC-051 响应式与可访问性

- 1280px 以上使用表格/主从布局，760–1279px 使用紧凑表格或双栏，760px 以下使用卡片列表。
- 键盘可完成二级导航、筛选、分页、打开详情和确认对话框。
- 焦点状态可见，状态标签具有文本，表头和排序状态可被读屏软件识别。
- 遵守 `prefers-reduced-motion`；内容不依赖 hover 才能访问。

#### FR-DC-052 埋点

记录不含正文的产品事件：进入数据中心、切换二级页、搜索/筛选、打开文档、打开原件、打开
locator、查看 revision、查看运行、发起重处理、修改可见性、打开量化版本、跳转量化实验和失败
恢复。事件关联 Actor、对象 ID、入口页面、状态和时间，不记录搜索正文、文档正文或凭证。

## 7. 核心状态口径

### 7.1 文档内容状态

| 状态 | 页面含义 | 允许行为 |
| --- | --- | --- |
| 待核验 | 内容/授权尚未完成准入 | 仅管理员处理，不进入事实回答 |
| 标题索引 | 只有标题等元数据可检索 | 可发现、可看原件、可提交解析，不作为正文事实 |
| 原件已归档 | 对象已保存但未证明解析完成 | 可看原件，不能等同完整正文 |
| 完整正文 | 活动 revision 有成功解析和可定位片段 | 可检索、引用和原文回查 |
| 合成样例 | 项目自有、明确为演示/测试 | 必须显示样例标识，不冒充真实披露 |

“原件归档”“授权核验”“正文解析”“索引可用”是相互独立的维度，前端不得合并成一个模糊的
“已完成”。

### 7.2 量化数据状态

| 状态 | 含义 |
| --- | --- |
| candidate | 已构建并隔离，等待人工复核；不可用于正式研究运行 |
| frozen/registered | 清单和子资产哈希通过，已登记为不可变版本 |
| default | 当前部署选择的已登记冻结版本，只能有一个 |
| blocked | 授权、哈希、覆盖或能力门禁失败 |
| superseded | 被新默认版本替代，但历史运行仍可复算 |

数据版本切换只改变默认引用，不覆盖或删除旧版本。

## 8. API 与数据契约需求

### 8.1 复用现有接口

- `GET /api/assets/inventory`
- `GET /api/assets/hybrid-search`
- `POST /api/assets/search-index/rebuild`
- `PATCH /api/assets/documents/{document_id}/visibility`
- `DELETE /api/assets/documents/{document_id}`
- `POST /api/assets/ingestion-runs/reprocess`
- `GET /api/documents/{document_id}/segments/{ordinal}`
- `GET /api/quant/catalog`
- `GET /api/quant/portfolio-backtests`（只用于关联运行计数或跳转，不在数据中心展示收益详情）

### 8.2 首版必须补充的只读接口

具体命名以契约评审为准，至少需要以下能力：

| 接口能力 | 建议路径 | 关键要求 |
| --- | --- | --- |
| 数据中心总览 | `GET /api/assets/overview` | Actor 范围聚合、`as_of`、需要关注项、最近运行 |
| 文档分页目录 | `GET /api/assets/documents` | 服务端筛选/排序/分页，不回传不可见总数 |
| 文档详情 | `GET /api/assets/documents/{document_id}` | 元数据、关系、状态、`allowed_actions` |
| revision 列表 | `GET /api/assets/documents/{document_id}/revisions` | 不可变历史、分页或游标 |
| 处理运行列表 | `GET /api/assets/documents/{document_id}/ingestion-runs` | 版本、状态、质量摘要、脱敏错误 |
| 来源目录 | `GET /api/assets/sources` | 授权、范围、资产数、最近状态 |
| 全局运行目录 | `GET /api/assets/ingestion-runs` | 运行类型/状态/时间筛选 |
| 原件访问 | `GET /api/assets/documents/{document_id}/content` | 再鉴权、短时响应、审计、内容处置 |
| 恢复软删除文档 | `POST /api/assets/documents/{document_id}/restore` | 管理员权限、冲突检查、审计，不恢复物理缺失对象 |
| 行情数据集详情 | `GET /api/quant/market-datasets/{dataset_id}` | 能力矩阵、限制、子资产校验和关联计数 |

候选量化刷新需要先把调度报告登记为可查询的运行记录，再增加 `GET /api/quant/refresh-runs`；该接口
可排入增强版本，不阻塞首版已登记冻结数据目录。

### 8.3 分页与响应约束

- 列表统一返回 `items`、`page`/`cursor`、`page_size`、`total`（仅当前 Actor 可见范围）和排序口径。
- ID、时间、枚举、哈希和 capability 使用明确字段，不把关键业务状态埋在任意 `detail` JSON 中。
- 后端返回稳定枚举码和用户可读摘要；前端不依赖中文字符串反推状态逻辑。
- 操作响应返回新的对象状态和 audit/trace ID，前端成功后定向刷新相关 query。
- 契约先更新 `contracts/api/openapi.yaml` 和错误码，再实现前后端。

## 9. 安全、审计与工程约束

- 权限过滤先于搜索、排序、聚合和分页。
- 对象存储桶、数据库、Redis、MinIO 管理面和内部 API 不向浏览器直接暴露。
- 文件名、MIME、响应头和内容处置必须防止脚本执行；不安全类型只允许下载。
- 外部来源 URL 只能展示受控域名或由后端完成跳转校验，禁止 `javascript:`、任意重定向和模型生成 URL。
- 错误详情不包含 Token、完整内部 Origin、对象存储凭证、本地路径或正文。
- 所有治理写操作保留 append-only/soft-delete 原则，不能从 UI 物理删除历史资产。
- 在线请求不导入或执行 `analytics` 离线采集；数据刷新继续通过独立任务和冻结/发布流程。
- 前端使用 React Query，query key 必须隔离 Actor/权限版本；退出登录清理缓存。

## 10. 验收场景

### AC-01 标题索引边界

搜索一份仅有标题索引的公告，列表和详情均显示“公告标题（非正文）”；可以查看已归档原件，但
页面不会出现伪正文，也不会标记“可支撑 AI 事实回答”。

### AC-02 完整正文回查

从全局搜索或 AI 引用进入指定 locator，数据中心打开正确文档和片段；当前 Actor 无权时返回 404，
不显示标题或来源摘要。

### AC-03 谱系追溯

打开存在失败后重试成功的文档，可同时看到失败运行和成功运行、对应 revision、处理器版本和质量
摘要；历史记录没有被最新成功结果覆盖。

### AC-04 受控重处理

资产管理员对活动文档发起重处理，页面显示入队状态和追踪 ID，并可跳转任务中心；普通研究员不
看到按钮，直接调用接口得到 403/404。

### AC-05 量化版本边界

打开当前默认行情版本，页面显示实际覆盖期、A 股点时市值能力和港股/FX 限制。包含港股时不得把
“A 股市值中性可用”显示为整个组合能力。

### AC-06 候选不自动发布

增量任务产生候选后，候选仅显示“待人工发布”。刷新页面、打开详情或进入量化实验都不会自动把
候选登记为默认版本。

### AC-07 共享环境多账号

至少使用资产管理员、研究员和只读成员三个账户分别验证聚合数、列表、详情、原件和操作；任一账户
退出后登录另一账户，前一账户的数据不出现在缓存中。

### AC-08 异常恢复

API、Worker 或对象存储短时不可用时，页面保留 URL、筛选和已加载信息，给出可重试/跳转任务中心
提示；不回退到 Mock 数据。

## 11. 依赖与风险

| 风险/依赖 | 影响 | 应对 |
| --- | --- | --- |
| 当前只有聚合和检索 API，没有文档目录/详情契约 | 前端无法实现真实产品闭环 | 契约先行，先补只读 API 再开发页面 |
| 3,784/3,792 份资料只有标题索引 | 资料可发现但正文能力有限 | 显式状态与待解析入口，不用 AI 或 UI 补造正文 |
| revision/运行数量较大 | 一次加载导致慢查询和前端卡顿 | 服务端分页、索引验证、详情按需加载 |
| 全局搜索/问答与数据中心并行修改 `App.tsx/api.ts/types.ts/CSS` | 合并冲突风险高 | 先拆通用原文抽屉和 API 类型文件，约定路由/查询参数，小步提交 |
| 量化候选报告当前主要位于 CI artifact/`.runtime` | 无法稳定展示候选 | 先展示已登记目录；后续把刷新运行持久化后再开放候选页 |
| 共享环境仅 2C4G | 并发检索、聚合和问答可能争用资源 | 列表分页、聚合缓存、查询上限和分接口性能观测 |
| 角色模型尚未完全正式化 | 前端按钮口径可能漂移 | 以后端 `allowed_actions` 为准，不硬编码角色名称 |
| 原件在线预览存在安全风险 | XSS、内容嗅探或越权下载 | MIME 白名单、Content-Disposition、短时鉴权和审计 |

## 12. 完成定义（Definition of Done）

满足以下条件才视为数据中心首版完成：

1. `/assets` 已升级为数据中心，数据总览、研究资料、量化数据和数据源/运行入口可用；
2. 文档目录、详情、原件、locator、revision 和处理运行均连接真实 API；
3. 已登记量化数据版本、信号集、能力和限制可以查看并深链到量化实验；
4. 标题索引、原件归档、完整正文、候选和默认版本的状态边界通过验收；
5. 权限、缓存隔离、原件访问、审计和软删除满足安全要求；
6. OpenAPI、错误码、前后端类型和实现一致，新增接口具备单元/集成/契约测试；
7. Ruff、format、mypy、Import Linter、Python 全量测试、PostgreSQL 集成测试、前端 lint/测试/build
   全部通过；
8. 列表和详情 P95 达标，3,792 份文档规模下分页、筛选和深链可稳定使用；
9. 在共享集成环境使用至少三个不同权限账户完成端到端验收；
10. 发布记录包含提交 SHA、镜像标签、迁移 head、备份、验收证据、已知限制和回退结果。
