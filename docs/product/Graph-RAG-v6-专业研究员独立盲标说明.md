# Graph RAG v6 专业研究员独立盲标说明

版本：`graph-relevance-v6-blind`  
任务量：30 个全新查询 × 每查询 10 个候选，共 300 行  
回传文件名：`Graph-RAG-v6_专业研究员独立盲标工作簿_已完成_<研究员代号>.xlsx`

## 独立性要求

1. 由一名具备公司研究或行业研究经验的研究员独立完成，不查看模型排名、v3/v4/v5 标签、
   回归报告或其他标注者答案。
2. 只根据工作簿中的查询假设、公告标题、关键证据原文及原文链接判断；不修改 A:M 冻结题面。
3. 同一家公司下的多个查询共享同一组 10 个候选，但每个“查询—候选”关系必须独立判断，
   不能因为某文档对另一个查询相关就复制等级。

## 必填字段

只填写工作表 `v6盲标` 的 N:R 黄色区域，五项均不能为空：

| 字段 | 允许值或要求 |
| --- | --- |
| 相关性等级 | `0-无关`、`1-弱相关`、`2-间接相关`、`3-直接相关` |
| 关系路径可成立 | `是`、`否` |
| 标注理由 | 写明候选证据如何影响当前查询中的核心变量；建议不少于 20 个汉字 |
| 标注员 | 稳定的研究员代号，不填写真实姓名也可以 |
| 标注时间 | 带时区的 ISO 8601，例如 `2026-08-30T10:30:00+08:00` |

等级口径：

- `3-直接相关`：候选直接披露、测量或决定查询的核心变量。
- `2-间接相关`：存在一条清晰、有业务依据且可复核的传导链。
- `1-弱相关`：主题相近，但证据不足以支持可靠传导链。
- `0-无关`：不能帮助判断查询，或只是治理、证券程序等无关事项。

“关系路径可成立”只回答从候选事实到查询假设是否存在可解释、可追溯的业务关系；主题相似
但无法说明传导方式时应选“否”。

## 回传前质检

在 `质检概览` 确认：

- 五项全部完成数为 300；
- 剩余未完成、无效相关性等级、无效路径选项均为 0；
- 每个查询完成候选数均为 10；
- 没有删除、增加、合并或替换行；
- 回传原始 XLSX，不复制到新工作簿，不另存为 CSV。

研究员无需运行模型、评测脚本或提供放量结论。回收后由项目方按关系样本 ID 合并标签、校验
冻结哈希并执行唯一一次 v6 评测；同一金标一旦开始评测即不可重复消费。
