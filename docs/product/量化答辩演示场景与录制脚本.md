# 量化答辩演示场景与录制脚本

## 1. 场景定位

产品内新增只读页面 `/quant/demo`，标题为“30 证券投资逻辑回测验证 · 全量确认情景”。它用于在短视频中完整表达以下闭环：

> AI 发现研究变化 → 研究员核验关系 → 方向与强度因子化 → 组合约束 → T+1 样本外回测 → 风险与可复算信息

该页面不是第二套回测器。它读取当前 V4 冻结行情，并调用正式的 `portfolio-research-v3` 组合计算引擎。为了保证录制稳定，情景输入按固定规则生成、只在内存中计算，不调用模型、不写数据库，也不会与真实 Evidence、Relation、Signal Set 或历史运行混合。

本地通过 `QUANT_DEMO_ENABLED=true` 开启。`.env.example` 默认关闭，避免上线后把假设记录误认为真实研究记录。

## 2. 分数在量化中的含义

人工确认事件因子的基础映射为：

```text
score = direction_sign × strength_weight

支持: +1      冲突: -1      中性: 0
高:   1.0     中:   0.7     低:   0.4
```

因此支持/高为 `+1.0`，支持/中为 `+0.7`，冲突/低为 `-0.4`。AI 置信度是复核优先级和质量诊断字段，不参与 Alpha 权重；否则模型的“自信程度”会被误当成经济方向强度。

这个分数不是评级、买卖指令或最终仓位。它在量化链路中的作用依次是：

1. 把不同证券的人工确认研究判断放到同一有符号尺度；
2. 在每个时点形成横截面排序，符号决定正负暴露，绝对值决定约束前的相对权重；
3. 经过总绝对值归一化；
4. 再施加单券上限、行业上限、ADV20 容量、停牌/涨跌停等约束；
5. 只在确认后的下一可交易日生效，最终形成研究组合净值、风险归因和样本外窗口。

它对应的是量化研究中的“事件型 Alpha 输入因子”，而不是价格动量、价值或质量等传统财务因子。

## 3. 中性为何为 0，以及本次修正

中性事件记 0 分作为“本条证据没有方向贡献”是合理的；高/中/低只表达影响的重要程度，不能凭空为没有方向的事件制造正负暴露。因此中性任意强度的因子贡献均为 0。

但“因子贡献为 0”和“目标仓位归零”不是同一件事。当前 V3 引擎若收到某证券的新 0 分目标，会覆盖此前分数，下一次再平衡时可能关闭仓位。这把关系语义误解释成了状态动作。

答辩情景采用独立版本 `assumed-confirmation-neutral-noop-v1`：

- 中性事件继续保留在情景审计和统计中；
- 它不覆盖该证券此前仍有效的方向状态；
- 只有明确的撤销、失效、假设关闭或风险规则才应触发归零；
- 不静默改写既有 V3 历史运行，保证旧结果仍可复算。

后续正式方法版本建议增加显式 `event_action`：`update`、`no_op`、`close`，从数据契约上彻底区分这三种语义。

## 4. 固定演示样本

当前情景使用：

- 30 只 A 股冻结证券；
- 2023-12-01 至 2026-09-01 的 667 个交易日；
- 11 个跨期信号截面；
- 330 条假设已人工确认事件；
- 264 条方向性信号；
- 66 条中性 no-op 留痕；
- 547 个有效暴露交易日；
- 3,170 个前瞻收益观测；
- 30 只证券形成非零信号覆盖。

信号方向采用与证券序号、截面序号相关的固定轮换，不使用未来收益，也没有为了得到更好业绩而反向拟合。回测结果可能跑赢或跑输基准；视频应展示产品能力和研究纪律，不把收益数字作为 Alpha 证明。

## 5. 建议录制脚本（约 80 秒）

### 0–10 秒：进入演示

在“模型与因子”中点击“答辩演示”。停留在顶部标题和三个标签：受控答辩演示、假设数据、真实冻结行情。

旁白：

> 这里展示的是一条受控、可复算的量化验证链路。行情是真实冻结版本，研究确认记录是为了答辩构造的全量通过情景，不会写入真实研究库。

### 10–23 秒：解释为什么不再只有 2 只证券和 14 天

停留在五个样本指标卡。

旁白：

> 原真实样本只有 2 只证券形成方向信号、14 个有效交易日。全量确认情景扩展到 30 只证券、330 条事件、547 个有效暴露日和 3,170 个前瞻观测，因此可以完整展示样本门禁和回测流程。

### 23–38 秒：从投资逻辑到组合

滚动到四步流程。

旁白：

> AI 先把新资料关联到投资假设，研究员逐条核验。确认后，方向和强度被转成事件因子，再经过单券、行业、容量和可交易性约束，最后严格从 T+1 开始验证。

### 38–53 秒：解释分数与中性

停留在分数矩阵和“中性 0 分，不等于清仓”。

旁白：

> 支持为正、冲突为负，强度决定绝对值；它只是横截面的相对研究暴露，不是交易指令。中性本条贡献为零，但在新策略中是 no-op，保留上一有效状态，只有明确撤销或失效才清零。

### 53–70 秒：回测结果

停留在结果指标和净值曲线。

旁白：

> 下方结果由正式组合引擎计算，包含交易成本、最大回撤、基准、信息比率、119 次再平衡和滚动样本外窗口。达到自动样本门槛只表示可提交研究评审，产品仍禁止直接宣称 Alpha。

### 70–80 秒：可追溯与收束

滚动到最近一期演示信号及底部版本信息。

旁白：

> 每条信号仍能看到证券、投资逻辑、证据摘要、方向、强度和组合作用；行情、情景策略和方法版本均有稳定标识，可以重复复算。

## 6. 演示口径红线

可以说：

- 产品已具备从投资逻辑到事件因子、再到多证券回测的完整工程链路；
- 当前情景通过 30 证券、长期区间验证了样本门禁、成本、风险约束和可复算性；
- 后续只需持续积累真实人工确认事件，即可用同一链路开展正式研究。

不应说：

- 330 条事件都是历史真实人工确认；
- 当前收益证明模型存在 Alpha；
- 中性事件会自动建议平仓；
- 回测结果能够直接生成评级、调仓或订单。
