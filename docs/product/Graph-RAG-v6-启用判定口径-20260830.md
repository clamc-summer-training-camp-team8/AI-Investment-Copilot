# Graph RAG v6 启用判定口径

版本：`graph-rag-v6-activation-policy-v1`

本口径在消费 `graph-relevance-v6-blind` 唯一一次正式评测之前冻结，用于落实“只要 Graph RAG
性能不是太差，后续就开启”的产品决策，同时不改写原 14 项权威盲测门禁及其历史结论。

## 判定顺序

1. 以下安全与交付硬门必须全部通过，否则保持 `RAG_GRAPH_ENABLED=false`：
   - 候选池合规率等于 1.0；
   - 未判断返回数等于 0；
   - 权限、跨证券、未来信息、诱饵正文泄漏均等于 0；
   - 路径来源完整率不低于 0.95；
   - 至少 20 个查询存在正例。
2. “性能不是太差”定义为以下质量条件全部满足：
   - Recall@5 不低于 0.65，且相对同版文本基线下降不超过 0.05；
   - MRR 不低于 0.65，且相对同版文本基线下降不超过 0.05；
   - NDCG@5 不低于 0.65；
   - Top-1 正确率不低于 0.60。
3. 若原 14 项权威门禁 14/14 通过，开启 Graph RAG 并启用 Evidence Fusion 排序：
   `RAG_GRAPH_ENABLED=true`、`RAG_GRAPH_ASSIST_ONLY=false`。
4. 若原 14 项未全通过、但本口径第 1、2 项全部通过，开启 Graph RAG 的保序辅助模式：
   `RAG_GRAPH_ENABLED=true`、`RAG_GRAPH_ASSIST_ONLY=true`。此模式实际使用图路径、图分与不足补位，
   但不让 Graph 改写文本共同候选的相对顺序。
5. 原 14 项结果继续原样记录；产品启用判定不得把未通过的权威盲测改称通过。

## 上线约束

- 开启后必须保留请求级候选池、权限、证券与时间边界。
- 运行时异常、图数据缺失或路径不可用时自动回退到文本检索。
- 线上继续记录 Graph 路径覆盖、原文引用、延迟和人工确认/驳回信号；任何泄漏立即关闭 Graph。
