## 3. 本次纳入范围

### 3.1 Phase 2 与共享环境基线

- 保留 Phase 2 三分支集成提交及冲突裁决记录；
- 保留 Phase 3 共享环境、受治理量化能力、数据库认证与备份恢复修复作为父提交历史；
- 在集成 Compose 中显式加入搜索、知识问答和复盘中心功能开关，默认保持受控状态。

### 3.2 数据资产治理与量化关系复核

- 增加标题索引原件的全文回填、重复文档受控归并和检索 locator 血缘对账脚本；
- 增加大文档批处理、PDF/OCR 降级和索引批量写入能力；
- 保留第三只 A 股候选关系、研究员回执、一手公告、验证结果及本地受控应用链路；
- 不把关系复核自动升级为正式证据或投资结论。

### 3.3 全局搜索与知识库 AI 问答

- 增加权限感知全局搜索 API、服务和顶部搜索交互；
- 增加带引用白名单的知识库问答 Schema、Skill、Provider、API 和前端助手；
- 标题索引、越权资料、未来资料和候选池外 locator 不进入事实回答；
- 搜索与问答开关解耦，模型不可用不影响搜索和既有人工流程。

### 3.4 数据中心

- 增加权限优先的数据总览、研究资料、Revision、来源、处理运行和原件访问；
- 增加量化行情数据集详情、清单哈希、能力限制、信号集和历史运行展示；
- 前端 `/assets` 升级为数据中心并保留深链、筛选、分页、详情和 locator 回查；
- 管理员身份不会自动扩大研究正文的访问范围。

### 3.5 复盘中心 P0

- 增加 `0018_retrospective_center` 迁移和复盘、来源、不可变版本三张表；
- 增加来源预检/冻结、草稿保存、乐观锁、评审、发布、修订、归档和导出主链；
- 增加只基于冻结且当前可见来源的 AI 候选，AI 不自动覆盖人工正文或其他业务对象；
- 前端 `/retrospective` 总览、列表、创建、详情和编辑全部连接真实 API；
- P1 经验库、量化附录和 PDF 导出未纳入本次 P0。
