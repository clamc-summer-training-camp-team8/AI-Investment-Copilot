## 重要数据结论

现有“每家公司约 5 条投资逻辑”主要是同一投资逻辑的五个季度版本，而不是五个平级研究角度。主题标准化按核心表述合并后，多数公司只有一个独立主题。

因此当前完成的是：

```text
季度版本去重
→ 独立主题物化
→ 假设/指标/证据聚合
→ 八维评分与冲突扣分
→ 主主题上下文返回
```

当前不能据此宣称已完成公司内 3～5 个独立主题的有效竞争排序。若需要每家公司维护多个研究角度，下一批数据必须从已有核心假设和新增证据中归纳真正不同的候选主题，而不能把季度版本重新拆开冒充不同主题。

## 第二轮：多主题候选层

已继续从九家公司跨季度稳定核心假设中派生研究角度。派生主题不是季度版本，而是需求与出货、盈利质量、产能与扩张等不同验证路径。

- 九家公司主题数由 10 个扩展为 40 个。
- 常规公司形成 1 个综合主逻辑与 3 个假设簇主题。
- 中芯国际因存在两个不同综合逻辑及两套历史假设，共形成 8 个主题。
- 单指标、无直接证据或可验证性不足的窄主题标记为 `PRIMARY_TOPIC_GATE_FAILED`。
- 满足至少两个指标、直接证据和可验证性门槛的主题标记为 `PRIMARY_TOPIC_ELIGIBLE`。
- 排序器保证合格主题优先于不合格窄主题；窄主题仅作为备选研究角度保留。
- 吉利汽车真实接口现返回：综合整车逻辑为主主题，需求与出货、盈利质量、产能与扩张为三个备选主题。

## 第三轮：当前模型语义复核

当前模型已对 11 个综合主主题候选进行离线语义复核。复核输入包含主题陈述、指标、支持/冲突证据及引用定位；复核仅判断主题完整性、因果关系、公司特异性和主主题资格，不把模型判断伪装成新增事实。

- 批准主主题：云南白药、吉利汽车、北方华创、比亚迪、小鹏汽车、恒瑞医药、药明康德。
- 降级为“待补证据备选主题”：兆易创新和中芯国际。
- 兆易创新被降级的原因：当前支持与冲突均主要为公告标题，缺少可验证存储周期、库存及毛利率传导的正文证据。
- 中芯国际被降级的原因：当前支持侧未直接证明利用率和收入修复，存在资本开支现金流反证；另一条历史修复逻辑缺少同期支持证据。
- API 在没有合格主主题时返回 `primary_topic = null`，不再把得分较高但已被复核拒绝的主题展示成主投资逻辑。

复核记录：`analytics/experiments/logic-topic-current-model-review-20260830.json`。

## 第四轮：兆易创新与中芯国际正文补证及复核修正

复核输入导出器已改为优先抽取直接、较完整且较新的证据，并按引用定位去重。此前对两家公司的“标题证据不足”结论源于复核包先返回公告标题，而非数据库缺失官方年报事实。

- 中芯国际：已定位 2025 年年报正文，包含销售收入 673.23 亿元、产能利用率 93.5%、毛利率 22%及月产能规模；投资活动现金流增加仍保留为反证。
- 两家公司的综合主题均经当前模型重新批准为主主题。
- 兆易创新的投资现金流扩大、中芯国际的资本开支现金流压力继续保留为冲突证据，排序分中仍受冲突惩罚影响。

真实 API 已验证：两家公司都返回一个合格 `primary_topic` 和三个备选主题。

## 第五轮：主题排序金标与回归门禁

已冻结第一版主题排序金标 `logic-topic-ranking-gold-v1-20260830`：九家公司各五项判断，共 45 项，覆盖主主题 Top-1、主主题与三个备选主题的两两排序及主主题资格门槛。

- 当前回归结果：45/45 通过，Top-1、两两排序和主主题资格均为 100%。
- 金标状态：沿用产品负责人已接受的程序金标口径。
- 门禁用途：防止后续主题、特征、模型复核或排序器改动破坏当前已冻结判断。
- 限制：该金标与当前模型复核和规则存在同源部分，不得把 100% 解读为独立业务准确率。
- 下一轮：引入独立研究员标注或样本外事件，重点测量新支持、重大反证和主主题切换的重排正确率。

## 后续门槛

1. 使用高级模型复核主题归并、公司特异性和因果强度，并保存引用。
2. 为当前只有一个合格主主题的公司补足第二个具备两个以上指标的独立主题。
3. 建立不少于 45 组独立主题比较金标。
4. 在存在至少两个合格主题的公司内评估 Top-1、Top-3 和反证重排。
5. 达到执行方案门槛后，才把主题快照由 `provisional` 提升为正式试用状态。
