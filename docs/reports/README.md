# 项目报告

本目录保存 AI Investment Copilot 的阶段性综合报告。报告基于产品需求、代码、数据、评测和
运行验收材料编写；若实现或评测口径发生变化，应同步更新报告版本和工程基线。

## 第一阶段

当前报告版本对应三分支集成基线 `phase1-integrated`，合并了后端/数据、AI Agent Runtime
框架与 React 固定场景前端。报告中的规模与门禁数据均以合并后代码重新统计和验证。

- [第一阶段项目报告](第一阶段项目报告.md)：面向项目组、业务、产品和管理读者，说明背景、
  目标、范围、产品成果、验收结论、风险和下一阶段计划。
- [第一阶段技术报告](第一阶段技术报告.md)：面向研发、架构、测试、运维和安全读者，说明
  架构、数据模型、关键链路、AI/RAG、安全、测试和部署实现。

两份报告中的投资与 AI 效果结论均只适用于所列样本和评测口径，不构成投资建议。
