# Graph RAG v4 专业研究员独立盲标包

## 交付内容

- `v4_专业研究员独立盲标工作簿.xlsx`：推荐使用，内含标注口径、下拉选项和完成度质检；
- `v4_专业研究员独立盲标原始表.csv`：与冻结包一致的 CSV 备用件；
- `blind_manifest.json`：候选池冻结记录与文件哈希；
- `model_lock.json`：标签回收前锁定的检索实现、权重与候选池哈希。

## 研究员操作

1. 打开 XLSX，先阅读“标注说明”；
2. 在“v4盲标”工作表中只填写 N:R 黄色区域：
   - 相关性等级；
   - 关系路径可成立；
   - 标注理由；
   - 标注员；
   - 标注时间；
3. 不修改 A:M 的冻结题面，不删除、增加或合并候选行；
4. 有疑问时打开“候选原文链接”，按“关键证据定位”核对原文；
5. 标注时间使用带时区 ISO 8601，例如 `2026-08-27T10:30:00+08:00`；
6. 在“质检概览”确认：五项全部完成为 240、剩余未完成为 0、无效选项均为 0；
7. 回传原始 XLSX 文件。

## 独立性要求

- 请研究员独立完成判断，不参考 v3 标签、v3 分数或模型排序分数；
- 本包共 30 个新查询，每查询 8 个候选，共 240 行，覆盖 9 家公司与 195 份不同公告；
- v3 查询复用为 0，v3 候选原文复用为 0；
- 候选顺序已冻结，检索实现与 0.35/0.65 文本/关系权重已在标签回收前锁定；
- XLSX 为便于阅读会用上海时区展示日期。回收时只提取 N:R 标签，并按“关系样本ID”合并回
  冻结 CSV，因此不会以工作簿日期显示格式替换冻结题面。

## 相关性等级

- `3-直接相关`：直接测量、披露或决定查询中的核心变量；
- `2-间接相关`：通过一条清晰且有业务依据的因果链影响查询；
- `1-弱相关`：主题相近，但缺少可靠或充分的传导链；
- `0-无关`：不能帮助判断查询，或仅为治理、证券程序事项。

标注理由必须具体、可复核，不能只填写“相关”“无关”或重复等级名称。
