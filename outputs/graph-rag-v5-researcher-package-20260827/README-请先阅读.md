# Graph RAG v5 专业研究员独立盲标包

## 任务目标

请对工作簿中的 300 个“查询—候选文档”关系逐行独立判断相关性。本轮包含 30 个全新查询，每个查询 10 个候选，覆盖 9 家公司、90 份唯一候选文档。

同一家公司下的查询使用完全相同的候选文档池。这是盲标协议的一部分，请仅根据“当前查询假设”和候选证据本身判断，不要因为同一文档在其他查询中出现而复用结论。

## 使用文件

- 首选：`Graph-RAG-v5_专业研究员独立盲标工作簿.xlsx`
- 备用：`Graph-RAG-v5_专业研究员独立盲标原始表.csv`

请优先使用 XLSX。它包含下拉选项、填写说明和自动质检公式。CSV 仅用于工作簿无法打开时的备用导入，不要同时提交两套不同结果。

## 填写方法

1. 先阅读工作簿的“标注说明”。
2. 只填写 `v5盲标` 工作表 N:R 五列黄色区域：相关性等级、关系路径可成立、标注理由、标注员、标注时间。
3. 不得修改 A:M 的冻结题面，不得删除、增加、合并或替换行。
4. 每行都必须填写五项；标注理由需要能被复核，不能只写“相关”或“无关”。
5. 标注时间使用带时区的 ISO 8601，例如 `2026-08-28T10:30:00+08:00`。
6. 可打开“候选原文链接”核对公告和页码；若 PDF 文本抽取出现乱码，以链接中的原始公告为准。

## 回传前质检

打开“质检概览”，确认：

- 五项全部完成 = 300；
- 剩余未完成 = 0；
- 无效相关性等级 = 0；
- 无效路径选项 = 0；
- 30 个查询的完成候选数均为 10，状态均为“已完成”。

完成后将文件命名为：

`Graph-RAG-v5_专业研究员独立盲标工作簿_已完成_<研究员代号>.xlsx`

请回传原始 XLSX 文件，不要复制到新工作簿，也不要使用会改变字段名、公式或下拉选项的软件另存。
