# 九家公司周期指标调研

本目录只保存供 Agent 检索的指标知识目录，不保存生产观测值。结构化源文件是
`metric_catalog.json`，当前版本 `nine-company-metric-catalog-v1`，核验日期
2026-08-27。

## 已验证的数据层级

| 层级 | 频率 | 九家公司覆盖 | 推荐用途 |
| --- | --- | --- | --- |
| 前复权行情 | 交易日 | 全部覆盖；实测每家公司均返回 2026-08-03 至 2026-08-26 共 18 个交易日 | 收益、波动和事件窗口代理，不能替代经营验证 |
| 收入、同比、毛利率 | 随财报 | 全部覆盖；A 股通常季度，港股通常半年/年度且需要单独口径映射 | 验证需求、放量、价格和盈利传导 |
| 利润、现金流、研发、存货 | 季/半年/年 | A 股可使用结构化 API，港股以 F10 和法定报告交叉复核 | 验证盈利质量、创新投入、回款和库存风险 |
| 公司特有经营指标 | 月/季 | 按公司分别登记，不做同业强行齐套 | 直接验证销量、交付、产能利用率等业务假设 |
| 监管或产品事件 | 日轮询、月/事件汇总 | 医药公司可获得，但实体匹配和里程碑价值需要复核 | 验证研发管线和商业化进展 |

## 来源与上线约束

- 腾讯行情和东方财富 F10 已用于本地试验，但生产授权、限频和稳定性仍需确认；
- Tushare Pro 可作为 A 股结构化备选源，需要 Token 和对应接口积分；
- 公司 IR、上深港交易所和国家药监部门公开披露应保存原文、locator、披露时间和抓取时间；
- 同一指标必须固定公式、单位、币种、累计/单期口径和版本；口径变化时新增版本，不覆盖历史；
- 抓取频率与观察频率分开存储，避免把“每日检查财报”误解为“每日财务指标”；
- 任一来源中断时可以切换备选源，但正式观测必须记录最终来源，不能静默混接不同口径。

## 阈值数据要求

阈值工具只接收截至 `as_of` 已公开的同公司、同指标版本、同单位观测。历史分位至少需要
8 期，建议 12 期以上；结构性变化、会计口径变化、重大并购和一次性因素由研究员复核。
若有带日期和来源的公司指引/研究预期，则优先作为候选参考。证据不足时返回空阈值，
不会让模型根据常识补数。
