# 独立盲标表 v2 填写说明

- 文件：`mentor_blind_annotation_v2.csv`，59 条，UTF-8 with BOM，Excel 直接双击可打开
- 抽样版本：`blind-sample-v2-20260811`，随机种子 20260811，抽样总体 `events.csv` 全部 3784 条
- 用途：作为**独立金标**，度量不含循环的真实准确率（对应 GAP-004 / DA-AC-05）
- 预计用时：约 30 分钟

## 为什么需要这份表

现有金标由程序化预标注加规则裁决产生，与被评测对象 `candidate_v2` 的词表同源。
同源意味着"规则复现规则"，测出来的准确率不能读作模型能力。

标注一致性指标现在也失去了诊断能力：`annotation_stats.json` 里 `direction_kappa = 1.0`，
但这个 1.0 来自两名标注者在 2540 条上都判"无关"、289 条都判"中性"——
双方没有可分歧的空间。只有引入独立于抽取规则的第三方标注，一致性指标才重新有意义。

这份表**刻意不含任何已有标注结果**，避免锚定。

## 只需填 5 列

表的前 12 列是给判断用的信息（公司、日期、标题、链接、该公司三条核心假设原文），不用改。
要填的是后 5 列：

| 列 | 填什么 | 取值 |
| --- | --- | --- |
| `关联假设` | 这条公告是哪条假设的证据 | `H1-需求与出货` / `H2-盈利质量` / `H3-产能与扩张` / 留空（判无关时） |
| `影响方向` | 相对该假设的影响 | `支持` / `冲突` / `中性` / `无关` |
| `判断理由` | 一句话即可，建议写明依据的原文位置或数字 | 自由文本 |
| `标注人` | 姓名或内部 ID | 自由文本 |
| `标注时间` | ISO 8601 | 如 `2026-08-12T10:30:00+08:00` |

填写约束：判 `无关` 时 `关联假设` 留空；判其他三种方向时 `关联假设` 必填。

## 四个方向的区别

`中性`与`无关`对下游影响完全不同，这是最需要区分的一组：

| 方向 | 含义 | 下游处理 |
| --- | --- | --- |
| `支持` | 该证据使假设更可能成立 | 进证据链，计入支持侧 |
| `冲突` | 该证据使假设更可能不成立 | 进证据链，累计触发失效预警 |
| `中性` | **相关但方向未定**，需等后续信息 | 进证据链，留待补充 |
| `无关` | **这类公告不进入证据链** | 不进证据链 |

方向指的是"相对该假设的影响"，不是股价方向，也不是情绪好坏。

## 判断口径：按顺序问三个问题

这三条来自 2026-08-11 的事件方向标注规则裁决，供参考，不是必须遵循——
**若您的业务判断与下述口径不同，请按您的判断填写**，差异本身就是这份表要发现的东西。

**问题一：频率允许它携带信息吗？**
一年发生 50 次以上的公告类型，单条一律判无关。恒瑞的临床试验批件 206 条落在
148 个不同日期，按 20 日窗口展开覆盖 97.7% 的交易日——一个 97.7% 时间都在亮的
信号是常量，不是信号。

**问题二：它改变了假设的可观测指标吗？**
H1 的度量口径是营业收入同比，H2 是毛利率。拿到 I 期临床批件对未来 1~2 年的
营业收入影响为零（临床到上市平均 8 年、成功率约 10%），它影响的是远期期权价值，
不是 H1 度量的东西。

**问题三：它是"进展"还是"结果"？**
研发链条上只有两个节点改变收入预期：获批上市（可以开卖了）、研发失败或撤回
（这条管线归零）。中间节点都是进展，进展不是结果。

一条补充口径：**没有金额的合作公告不是订单。** 框架协议不含对价、不含交付时点、
不构成履约义务，读不出金额时判无关而非支持。

## 两个需要注意的数据口径

1. **披露时间精度**：59 条里 45 条源数据时间为 00:00，无法区分盘前盘后，系统一律
   按盘后处理、收益窗口推到次日。表里 `披露时间是否精确` 列标注了每条的情况。

2. **只有标题、没有正文**：表里给的是公告标题与原文链接。部分标题读不出方向
   （如"产销快报""某月销量"），需要点开链接看正文数字。这正是当前系统的短板之一
   （事件抽取尚未扩到正文），您在这些条目上的判断对确认该短板的影响很有价值。

## 这份表的设计

抽样按披露类型分层，配额是按**类型**定的，不是按预期答案定的——避免把答案编进抽样。

| 维度 | 分布 |
| --- | --- |
| 假设映射类（可判方向） | 38 条 |
| 噪音类（治理、程式化、股权激励、回购、担保等） | 21 条 |
| 九家公司 | 恒瑞 9，北方华创 7，吉利 7，其余各 6 |
| 三行业 | 医药 21，芯片半导体 19，新能源汽车 19 |
| 样本内 / 样本外 | 28 / 31 |
| 日期范围 | 2024-01-04 ~ 2026-07-24 |

**21 条噪音必须保留。** 只标业务相关样本会让评测集偏易，测不出误报率——
当前 `candidate_v2` 的无关提醒率是 42.8%，这个数字只能靠含噪音的样本测出来。

呈现顺序已随机打散，同类型、同公司不相邻，避免按块套用同一判断。

## 拿到后我会做什么

1. 算不含循环的真实准确率与无关提醒率（`candidate_v2` vs 独立金标）
2. 用这 59 条重算 Cohen kappa，恢复一致性指标的诊断能力
3. 差异集中的类型进入下一轮裁决队列

## 一份参考：上一版盲标表的发现

`mentor_blind_annotation.csv`（59 条，样本来自上一轮范围）已由项目侧先行试填。
其中 22 条可与现有 A/B 标注比对，**方向一致仅 8/22，Cohen kappa = 0.274**。
差异全部集中在一个模式上：产销数据 10 条、业绩预告 2 条、定期报告 2 条——
A/B 一律判"中性"，读正文后可判出明确方向。

那份试填是项目侧判断，不是独立金标，不能用于算真实准确率。它的作用是说明
"含数字的公告在只读标题时会被系统性地判成中性"这个问题真实存在。
本表（v2）才是要作为独立金标使用的那一份。
