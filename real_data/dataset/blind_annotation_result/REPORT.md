# 独立盲标金标评测报告

- 金标版本：`mentor-blind-gold-v2-20260811`
- 抽样版本：`blind-sample-v2-20260811`（种子 20260811，可复算）
- 样本：59 条，九家公司全覆盖，三行业 21/19/19，样本内外 28/31
- 标注人：`Codex-投研标注`，标注时间 2026-08-11T18:00:00+08:00
- 被评测对象：`analytics/pipelines/annotate_events.py` 的标注者 A 链路（含导师裁决层）

## 结论

**这是第一次不含循环的评测。** 此前所有准确率数字都由与被评测对象同源的规则产生，
不能读作能力。本轮金标独立标注，不复现管道的任何词表或规则。

一句话结论：**筛选已经不是瓶颈，方向判断是瓶颈，而且瓶颈的成因是只读标题。**

| 能力 | 指标 | 数值 |
| --- | --- | --- |
| 筛选（该不该进证据链） | 精确率 | 96.3% |
| | 召回率 | 86.7% |
| | 无关提醒率 | **3.7%**（1/27） |
| | 漏报率 | 13.3%（4/30） |
| 方向（进了之后是什么方向） | 全样本一致率 | 61.0%（36/59） |
| | **共同相关子集一致率** | **30.8%（8/26）** |
| 规则清晰度 | Cohen kappa | **0.423** |

## 这个结果推翻了裁决书的预判

裁决书 6.3 给出的画像是"高精度方向、低精度筛选"，据此把 P1 定为
"改 `candidate_v2` 的筛选而非方向词表"。独立金标显示**方向恰好相反**：

| | 裁决书（金标=规则） | 独立金标 |
| --- | --- | --- |
| 无关提醒率 | 42.8% | **3.7%** |
| 方向一致率 | 95.8% | **30.8%** |

裁决书那两个数字来自 `candidate_v2` 与程序化金标的对照，两者同源。
换成独立金标后，结论整体翻转：裁决层把噪音挡得很好（21 条噪音里 19 条判对，
R1/R10/R11/R15 命中的 16 条中 14 条与金标一致），但方向判断在双方都认为
相关的条目上只有 30.8% 命中。

**因此 P1 优先级应调整**：瓶颈不在筛选，在方向；而方向的成因不在词表，在信息源。

## 偏差的唯一主因：管道判中性，金标判出方向

23 条差异里 18 条是同一个模式——管道判"中性"，金标读正文后判出明确方向：

| 披露类型 | 条数 | 一致率 |
| --- | --- | --- |
| 定期报告 | 6 | 0% |
| 业绩预告 | 3 | 0% |
| 集采与准入 | 1 | 0% |
| 产销数据 | 8 | 12% |
| 投资与产能 | 3 | 33% |
| 融资 | 4 | 50% |
| 药品研发进展 / 注册上市 / 程式化 / 治理等 | 26 | 80%~100% |

规律很干净：**含数字但标题不含方向的类型，一致率接近 0；标题即可判定的类型，一致率接近 100%。**

管道判中性的 19 条里，18 条被金标判出了方向（16 支持、2 冲突）。
这不是方向词表选错了词，而是标题里根本没有方向信息。举几条金标理由：

- `#1` 小鹏 2025 年 1 月交付：正文 30,350 辆、同比 +268% → 支持
- `#47` 小鹏 2026 年 1 月交付：正文 20,011 辆、较上年同月 30,350 辆下降约 34% → **冲突**
- `#43` 兆易 2023 年度业绩预告：收入 57.66 亿元、同比 -29.08% → **冲突**
- `#9` 北方华创 2025Q1 业绩预告：收入 595,056.84 万元、同比 +23.35%~+50.91% → 支持

`#1` 与 `#47` 是同一家公司、同一类公告、同一个标题模板，正文方向完全相反。
只读标题的实现无法区分这两条——这就是 A4「产销快报必须读正文」那条判断的量化证据。

上述数字已逐条回原文 PDF 抽查核对，全部属实。

## 三条金标与裁决规则的冲突，建议进下一轮裁决

| 条目 | 规则 | 规则判 | 金标判 | 金标理由 |
| --- | --- | --- | --- | --- |
| `#51` 药明康德 2023 年度募资专项报告 | R10 | 无关 | 支持 H3 | 报告明确募投项目整体结项、不存在未达计划进度 |
| `#18` 吉利极氪收购领克销售股份 | R14 | 中性 | 支持 H3 | 极氪以 90 亿元收购并注资，实质推进品牌与平台整合 |
| `#8` 中芯国际独立财务顾问报告 | R10 | 无关 | 中性 H3 | 收购中芯北方 49% 少数股权有利整合，但不直接证明扩产匹配需求 |

`#51` 与 `#8` 都命中 R10（募资程序性文件判无关），金标却认为其中含有可用信息。
这三条指向同一个问题：**R10/R14 是按标题关键词写的，而这几份文件的信息在正文里。**
与上面那 18 条是同一个根因，不是独立缺陷。

另有 `#46` 北方华创放弃参股公司增资优先认购权，管道判支持、金标判无关
（非主营投资安排，不改变设备订单与交付能力）。这是本轮唯一一条假正例。

## kappa 恢复了诊断能力

| | kappa | 说明 |
| --- | --- | --- |
| `annotation_stats.json` 现值 | 1.000 | 两套程序化规则的相关性，无诊断意义 |
| v1 盲标（22 条可比） | 0.274 | 项目侧试填，样本来自上一轮范围 |
| **v2 独立金标（59 条）** | **0.423** | 可作为「标注规则是否清晰」的基线 |

0.423 属于"一般一致"区间。这个数字本身不是问题——它准确反映了当前规则在
含数字公告上的模糊地带。要提升它，靠的是补正文抽取，不是改词表。

从本版起，`annotation_stats.json` 的 `direction_kappa` 不应再作为标注规则清晰度的
证据引用，应引用本报告的 0.423。

## 样本内外没有显著差异

| | n | 方向一致率 |
| --- | --- | --- |
| 样本内 | 28 | 64.3% |
| 样本外 | 31 | 58.1% |

差 6.2pp，n 这么小时无法与随机波动区分。这条的意义是：**方向判断的短板不是过拟合
造成的，样本内外一样差**，属于实现层面的系统性缺陷，改了正文抽取两边都会改善。

## 建议的优先级调整

| 原优先级 | 事项 | 建议 |
| --- | --- | --- |
| P1 | 改 `candidate_v2` 的筛选而非方向词表 | **降级**。无关提醒率实测 3.7%，筛选不是瓶颈 |
| P1 | 正文抽取（A4） | **升为 P0**。18/23 的偏差、3 条规则冲突都是同一个根因 |
| P0 | 命中率与无条件基准同时输出 | 保持 |
| P0 | 同日同证券信号去重 | 保持（本次抽样已实现同公司同日去重） |

正文抽取的最小可用范围可以很窄：产销数据、定期报告、业绩预告三类
（本样本中 17 条，占偏差的 15 条），抽"营业收入同比""销量/交付量同比"两个字段即可。

## 限制

1. **单人标注，无法算标注者间一致性。** 本轮金标由一名标注人完成，
   kappa=0.423 衡量的是"金标 vs 管道"，不是"两名独立标注者之间"。
   要评估金标自身可靠性，需要第二名标注人对同一批（或其中 20%）独立标注。
2. **n=59，分层后每类仅 1~8 条。** 类型级一致率（如集采与准入 0/1）不构成结论，
   只用于定位偏差集中在哪里。
3. **标注时间为统一时间戳。** 59 条同为 `18:00:00+08:00`，无法还原逐条标注耗时，
   不能用于效率基线（`manual_baseline.csv` 仍为空）。
4. 本报告评测的是标注管道（标注者 A 链路），**不是 `candidate_v2`**。
   要得到 `candidate_v2` 的不含循环准确率，需用本金标重跑 `run_evaluation`。
5. 本报告不含收益或 Alpha 结论，不构成投资建议。
