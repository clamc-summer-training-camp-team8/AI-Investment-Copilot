# 三行业事件方向信号的 20 日超额收益对照实验

实验编号：EXP-20260811-001
状态：已完成一轮，结论等级 **探索性**

上一轮是 [EXP-20260809-001](../20260809-事件方向信号/README.md)（储能行业 3 家公司）。
本轮换了研究范围、基准与词表，两轮**不可直接比较**，因此另开目录而不是覆盖旧结果。

## 1. 经济假设（在看结果之前写下）

公告披露的经营类事件（产销交付、订单、业绩、产能投资、药品研发与准入）改变市场对
公司短期基本面的预期。若这类事件的方向判断包含尚未被价格完全反映的信息，则信号方向
与随后 20 个交易日的行业中性超额收益应存在**弱正相关**。

为什么可能不成立，也一并写下：

- A 股公告多为盘后披露，次日开盘即反映，20 日窗口内的超额更多由行业行情与流动性
  驱动，而非单条公告。
- 产销快报、交付数据这类高频披露事件已被市场充分预期，边际信息量低。
- 医药的临床批件属于高频程式化披露（恒瑞两年多有 200+ 条），单条批件对估值的
  边际影响极小，但它在样本里占比很高，会主导整体命中率。
- 跨行业后行业轮动幅度远大于个股事件效应，即使按行业中性化，残差仍可能以噪音为主。

预期结果：命中率接近 50%，即**信号无预测力**。这个预期写在前面，避免事后把任何
结果都解释成「符合预期」。

## 5. 结果标签

指标字典 MET-004：20 日行业中性超额收益。

- 基准：**按行业分别取**，事前确定，未更换
  - 半导体 → 科创50（000688）
  - 医药 → 中证医药（000913）
  - 新能源汽车 → 中证新能源汽车（399976）
- 复权：前复权（GAP-003 未关闭，口径固定并记录）
- 起算：披露日的**下一个交易日**（T+1）
- 生成：窗口结束后才生成，未结束标「待观察」
- 披露时刻缺失（本轮 3123/3784 = 83% 的公告时间为 00:00）：一律按盘后处理

**为什么不再用单一基准**：上一轮三家公司同处储能产业链，共用创业板指还算可比。
跨三个行业后，用同一个指数算超额等于把行业轮动当成个股 alpha。基准按行业取之后，
「超额」才是相对同行业的相对表现。

## 6. 偏差控制逐条声明（说明书 10.4）

| 偏差 | 本实验的控制方式 |
| --- | --- |
| 未来数据泄露 | T+1 起算；窗口结束后生成标签；`DQ-006` 由 `return_labels.py` 强制；披露时刻不明按盘后处理；失效阈值只用 2022Q1~2024Q3（全部早于最早建立日 2025-01-20）的历史确定 |
| 生存者偏差 | **未控制。** 九家公司均为当前正常经营的头部企业，样本天然带生存者偏差。本实验不做选股类结论 |
| 选择偏差 | 全部样本进入评测，分歧样本经裁决后保留而非丢弃；同时报告命中、误报、待观察 |
| 重复事件 | 按 `announcement_id` 去重（采集与合并两道） |
| 参数过拟合 | 词表只用样本内构造；样本外只评估一次；阈值与窗口未依据结果调整 |
| 标注者相关性 | 两名程序化标注者刻意保持独立：**不**把「获得/获批/受理」这类与事件类型高度重合的词加入标注者 B 的动作词表。加了会让 B 在 316 条医药样本上必然与 A 一致，方向 kappa 从 0.66 虚假抬到 0.89——抬上去的是标注者相关性，不是规则清晰度 |
| 市场错配 | **未控制。** 吉利与小鹏为港币计价，基准为人民币计价，汇率波动进入超额收益 |
| 交易可实现性 | **未考虑。** 不含停牌、涨跌停、成本、换手。因此结果不等同可交易收益 |

## 8. 已知限制

1. 金标未经业务导师确认（GAP-004）。
2. 抽取规则与金标规则词表重合 91%，评测数字偏乐观。这一轮重合度比上一轮的 81%
   更高，因为两边都补了同一批行业词——**准确率里「规则复现规则」的成分更大了**。
3. 样本九家公司、约 2.5 年，仍不足以支持任何因果结论。
4. 信号在三个行业间分布极不均衡：样本外医药 95 条、半导体 13 条、新能源汽车 0 条。
   任何按行业的命中率差异都可能只是样本量差异。
5. 20 日窗口内的超额收益受行业行情主导，单条事件的边际贡献难以分离。
6. 不含交易成本与可实现性约束。
7. 港股不强制季报，小鹏只有中报与年报，其单季度指标期数天然少于 A 股公司。

## 9. 下一轮验证计划

1. 取得导师确认的人工金标，重算全部效果指标。这是所有效果数字的前置条件。
2. 让抽取规则与金标规则**由不同人、依据不同材料**构造，降低 91% 的词表重合。
3. 事件抽取从标题扩到正文，检验方向判断在更长文本上的表现。
4. 补齐新能源汽车的样本外信号：现有规则在港股程式化公告上几乎全被排除，
   需要单独检查港股披露语言。
5. 增加 5 日与 60 日窗口，检验结论对窗口选择的敏感性。
