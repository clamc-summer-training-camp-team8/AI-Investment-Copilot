# 事件方向信号的 20 日超额收益对照实验

实验编号：EXP-20260809-001
状态：已完成一轮，结论等级 **探索性**

## 1. 经济假设（在看结果之前写下）

公告披露的经营类事件（产销、订单、业绩、产能投资）改变市场对公司短期基本面的预期。
若这类事件的方向判断包含尚未被价格完全反映的信息，则信号方向与随后 20 个交易日的
行业中性超额收益应存在**弱正相关**。

为什么可能不成立，也一并写下：

- A 股公告多为盘后披露，次日开盘即反映，20 日窗口内的超额更多由行业行情与流动性
  驱动，而非单条公告。
- 产销快报这类高频披露事件已被市场充分预期，边际信息量低。
- 三家公司同属一条产业链，行业中性化之后剩余的个股超额可能主要是噪音。

预期结果：命中率接近 50%，即**信号无预测力**。这个预期写在前面，避免事后把任何
结果都解释成「符合预期」。

## 6. 偏差控制逐条声明（说明书 10.4）

| 偏差 | 本实验的控制方式 |
| --- | --- |
| 未来数据泄露 | T+1 起算；窗口结束后生成标签；`DQ-006` 由 `return_labels.py` 强制；披露时刻不明按盘后处理 |
| 生存者偏差 | **未控制。** 三家公司均为当前正常经营的头部企业，样本天然带生存者偏差。本实验不做选股类结论 |
| 选择偏差 | 全部样本进入评测，分歧样本经裁决后保留而非丢弃；同时报告命中、误报、漏报 |
| 重复事件 | 同一公司同一日同类事件按 `content_hash` 去重 |
| 参数过拟合 | 词表只用样本内构造；样本外只评估一次；阈值与窗口未依据结果调整 |
| 交易可实现性 | **未考虑。** 不含停牌、涨跌停、成本、换手。因此结果不等同可交易收益 |

## 8. 已知限制

1. 金标未经业务导师确认（GAP-004）。
2. 抽取规则与金标规则词表重合 81%，评测数字偏乐观。
3. 样本仅 3 家公司、约 2.5 年，不足以支持任何因果结论。
4. 20 日窗口内的超额收益受行业行情主导，单条事件的边际贡献难以分离。
5. 不含交易成本与可实现性约束。
