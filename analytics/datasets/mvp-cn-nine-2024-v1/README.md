# 中国九公司 MVP 闭环验证数据集 v1

## 范围

- 芯片半导体：中芯国际、兆易创新、北方华创
- 医药：恒瑞医药、药明康德、云南白药
- 新能源汽车：比亚迪、吉利汽车、小鹏汽车
- 基线：2024Q1；历史回放事件：2024Q2、Q3、Q4
- 截止日：2025-04-26。截止日之后的事实不参与标签或状态计算。

## 数据与口径

`data/raw_observations.json` 收录 9 个案例、36 个观测值和 36 条来源记录。六家芯片/医药公司采用单季度营业收入；三家车企采用单季度销量或交付量。累计披露的数据以相邻累计值差分为单季度值，`locator` 明确记录推导式；年度报告的分季度表用于复核。

当前文件 SHA-256：`ceb55b769eea95b2e52233e19911ec9e7930f9df5e6392ec148d517c260722b2`。

期望值采用 `q1-scale-floor-v1`：在 Q1 披露日冻结一个不高于 Q1 实际值的整数量级下限，后续不调参。它是透明、可复算的流程验证基线，不是卖方一致预期，也不是研究员真实预测。

## 公开数据入库声明

数据来自上市公司官网、投资者关系页面、上交所/深交所/港交所披露或公开公告镜像。仓库只保存结构化事实、必要的短摘录和来源链接，不保存完整受版权保护报告。若来源撤回，可按 `source_document_id` 在交易所公告系统复核。

## 标注边界

`proxy_gold_direction` 由代理复核者按“实际值是否达到冻结阈值”确认，只能验证确认门、状态机与审计链。它不是由项目研究员制作的独立业务金标，不能用于宣称 AI 方向判断能力。

## 已知限制

- 选样是目的性样本，不代表行业总体，存在选择偏差。
- 使用单一核心指标，未覆盖利润、现金流、估值、政策和行情结果。
- 没有行情复权与行业中性收益标签，因此不验证 Alpha。
- 数据集在回放前构建，但本轮是事后历史验证，不是实时前瞻实验。
