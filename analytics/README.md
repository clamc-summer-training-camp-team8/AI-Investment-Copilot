# analytics — 数据分析与 Alpha 验证

主要维护：数据管道方向（问谁，不是评审权限）
基线文档：`docs/data/数据分析交付包/`

## 定位

离线模块。回答的问题是「AI 是否带来可度量的投研增量价值」，不参与线上请求。

数据分析师是工作台的数据驱动者，但不是独立的投资决策者（说明书文档结论）。

```
analytics/
├── pipelines/     四类数据管道
├── datasets/      评测集与金标集版本目录（符合授权边界的数据可进 git）
├── evaluation/    基线对照与效果指标
├── experiments/   候选信号实验，一实验一目录
└── notebooks/     探索性分析，不作为交付物
```

## 四类管道（说明书 T10）

| 管道 | 输入 | 关键处理 | 输出 |
| --- | --- | --- | --- |
| A 投研资料 | 研报、纪要、公告、财报、新闻、政策 | 清洗、证券映射、分段、版本与引用定位 | 标准文档、段落、证据 |
| B 结构化指标 | 财务、行情、行业、同业、预期数据 | 单位统一、报告期处理、同比环比、基准映射 | 指标观测值 |
| C 标签与结果 | 后续财报、行情、人工结论 | 生成基本面与收益窗口标签 | 结果标签 |
| D 评测实验 | AI 输出、基线输出、人工金标 | 版本固化、样本切分、指标计算 | 实验与评估报告 |

A 管道的线上部分在 `app/ingest`，这里做批量回填与历史样本构建。B 管道的计算口径复用 `app.calc`。

## 与 app/ 的关系

- **可以** import `app.calc`、`app.db`。
- **禁止** 被 `app/` 任何模块 import（`.importlinter` 强制）。线上代码不依赖离线实验代码。
- **禁止** 在这里重写一套计算口径。预期差、趋势、同业比较一律调 `app.calc`。离线和线上算出不同数字是最难排查也最伤信任的问题。

## 实验规范（说明书 10.2）

七步，缺一步的实验结论不予采纳：

1. **先写经济假设**，说明信号为什么可能与未来基本面或收益相关。写在实验目录的 `README.md` 里，提交时间早于结果。
2. **固化信号规则**。在看结果前固定模型、提示词、阈值和样本范围。
3. **建立基线**。至少比较关键词法、普通情绪分类或原人工流程之一。
4. **严格时间切分**。训练/调试样本与样本外评估按时间切分。
5. **构建结果标签**。按固定窗口生成基本面或行业中性超额收益。
6. **报告失败案例**。同时展示命中、误报、漏报和冲突样本。
7. **给出有限结论**。明确样本、口径、限制和下一轮验证计划。

一个实验一个目录：`experiments/YYYYMMDD-信号名/`，含 `README.md`（经济假设与限制）、配置、结果。目录一旦有结果就不再改配置，要改就开新实验。

## 偏差控制清单（说明书 10.4）

每个实验的 README 必须逐条声明如何控制：

| 偏差 | 要求 |
| --- | --- |
| 未来数据泄露 | 不使用披露日之后才可获得的字段 |
| 生存者偏差 | 历史样本不得只保留当前仍上市或表现良好的公司 |
| 选择偏差 | 不得只挑成功案例展示 |
| 重复事件 | 同一事实多次转载不得计为多个独立信号 |
| 参数过拟合 | 阈值和窗口不能根据样本外结果反复调整 |
| 交易可实现性 | 进入 P2 回测需考虑停牌、涨跌停、换手和成本 |

测试集在模型调试期间保持冻结。反复查看测试集会造成隐性过拟合，即使没有显式调参。

## 发布门槛（说明书 T16）

所有效果指标必须同时披露分母、样本时间范围、数据版本、模型版本和人工标注版本。

**仅有百分比、没有样本数的结果不得用于验收。**

## 表述红线（说明书 T6）

不得使用「AI 已证明能够稳定创造 Alpha」作为 MVP 结论。

合规表述：「AI 发现的候选信号在限定样本和实验口径下表现出增量信息价值，仍需更长周期样本外验证」。

这不是文字游戏。MVP 的样本量与时间跨度不足以支持因果结论，越界表述会造成合规问题。

## 金标集（说明书 12）

- 金标由研究员或具备金融业务判断能力的导师确认，数据分析师负责样本组织、版本管理和一致性统计。
- 首批双人标注不少于 20% 样本，用于检查规则是否清晰。
- 标注规则变更时创建新版本，并明确是否需要重标历史样本。

## 数据入库规则

`datasets/` 可以提交公开、可再分发且体积可控的数据本体，便于团队复现与协作。每个数据集仍须同时提交数据来源、披露时间、口径、切分方式和校验和；公开不等于无条件可复制，原文大文件应优先保存来源链接和必要的结构化摘录。

付费数据、内部研究资料、含个人信息的数据，以及许可条款不明确的数据不得提交。此类数据放在 `analytics/datasets/**/external/`，该目录由 `.gitignore` 排除。数据集 README 必须逐项声明授权边界。

## 待关闭的数据缺口

`docs/data/数据分析交付包/投研数据资产与指标字典 V1.0.xlsx` 的「MVP数据缺口」页登记了 GAP-001~005。其中三个高严重度缺口直接影响这个模块：

- GAP-001 优先行业与公司范围未定 → 当前只能用虚拟案例联调
- GAP-002 研究员预期值来源未定 → 预期差暂靠人工录入并记录来源
- GAP-003 行情复权与基准口径未定 → 收益标签仅展示虚拟计算

未关闭的缺口必须在验收结论中披露，不能默默用一个假设值代替。
